# 桌面背景与系统集成

## 静态背景

在「设置 → 外观」选择 PNG、JPG、JPEG、静态 WebP 或 BMP。仅支持静态图片；GIF、动态 WebP/APNG 和视频不再作为背景。扩展事务的背景选择遵守相同限制。

图片可裁剪，文件上限为 20 MB；缓存最长边不超过 1600 像素，并限制源图像尺寸。铺放方式、背景不透明度和各区域不透明度仍可调节。应用保存自己的裁剪副本，不修改或删除用户原文件。

0.4.0-beta.17 启动时会关闭旧动态背景配置并提示。原地升级后仅清理程序目录 VideoDecoder 中已知的旧解码器与专属许可文件；目录包含未知文件时不递归删除。背景管理目录的闲置应用副本沿用退出清理规则。用户原视频或图片不参与删除。音乐播放所需的 soundflow-ffmpeg 原生库与其许可继续保留。

## 开机自启动

设置中的「开机自启动」默认关闭，实际含义是在当前系统账户登录桌面后启动 Nonet。Windows 使用当前用户 Run 注册表项，Linux 使用当前用户 XDG autostart 文件，macOS 使用当前用户 LaunchAgent。无需管理员权限，也不会修改其他用户启动项。

系统注册位置属于操作系统集成，必须放在系统要求的位置；音乐、配置、背景等应用数据仍使用选定的数据目录。注册失败时显示错误并保留原开关状态。恢复默认设置会关闭 Nonet 的自启动。

更换便携程序位置后，正常启动时会更新已启用的注册路径。系统可能通过自身的启动管理、安全策略或权限阻止启动；Windows 的 StartupApproved 状态不会被应用绕过。关闭自启动不会结束正在播放的应用。

## 从文件夹新建歌单

点击侧栏歌单栏的新增按钮，在弹窗选择「以文件夹新建」，可多选目录。每个所选目录单独建立歌单，名称取该目录名，递归导入该目录及非链接子目录中的支持音频，并读取原有封面和同名歌词。相同目录在一次选择中只处理一次。

空目录会建立空歌单。歌曲在多个歌单中出现时共享音乐引用，不复制或删除源音频。名称超过现有 80 字符上限时缩短并显示提示。取消文件选择不创建歌单；中途取消导入会停止余下目录，已经完成的歌单及当前空歌单保留。
