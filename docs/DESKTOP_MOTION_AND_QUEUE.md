# 桌面动画、歌词与播放队列

本次为桌面功能更新；共享核心、CLI、Android、插件 Contract 和 SDK 程序集身份保持兼容。

## 播放列表浮层

播放栏中，桌面歌词按钮右侧为播放列表。点击展开当前实际播放队列，显示封面、歌曲、艺术家、时长和当前选中项；无封面时显示音乐占位图标。点击歌曲立即播放，浏览页面和播放来源保持不变。再次点击按钮、点击浮层外部、关闭按钮或按 Esc 收起。外部点击继续执行原来的操作。底部不再显示顺序播放提示。

鼠标可拖动整行，触摸和笔按住整行 420 ms 后拖动；长按前移动仍交给原生触摸滚动。队列不显示右侧拖动圆点。拖动显示从原模板生成的半透明歌曲副本，真实占位变淡；相邻行以 210 ms 二次曲线连续让位，快速反向从当前呈现位置继续。靠近列表边缘自动滚动；松手才提交实际队列，不切歌、不改变进度，也不改写来源歌单。拖动中按 Esc、关闭浮层或失去指针捕获会还原预览；自动切歌或外部刷新优先，过时的队列提交被拒绝。手动队列排序在收藏等来源编辑后保留；切换播放模式仍沿用原有模式顺序规则。

浮层适配深浅主题、小窗口和顶置播放栏；列表使用虚拟化，打开不会重建当前页面。开合动画同时改变透明度、缩放、弧线位移和圆角，快速重复点击从当前值反向继续。关闭完成后不再参与命中测试；隐藏、最小化和关闭窗口立即清理。

这是当前播放来源的实际播放顺序，不是另一个独立的收藏歌单。编辑歌单仍通过原歌单界面进行。

歌单歌曲的系统拖放使用相同的让位预览，支持非连续多选成组移动。预览只调整展示集合，松手后才通过原有歌单排序动作保存并加入撤销记录；Esc、离开目标、取消或数据刷新不会把临时顺序写入资料库。跨歌单添加、文件导入及拖到播放器播放保持原有行为，也不重新加入排序提示浮层。

行让位时，系统可能切换指针下的拖放目标，只发出 Leave/Enter 而暂不发出 Over。Enter 与 Over 使用同一更新路径，接续原来的虚影与动画，并取消旧目标的延迟清理；不会在经过其他歌曲时先撤销再重排。真正离开会恢复原序并隐藏虚影，返回列表仅收到 Enter 也立即恢复预览；切换播放器投放目标仍显示原播放提示。

## 桌面随机播放

- 开始播放或手动重新点歌时，对当前播放范围执行 Fisher–Yates 洗牌，所选歌曲放在首位。
- 下一首、上一首和自然播完沿固定队列前进或回退，队列循环后保持同一顺序。每轮不会提前重复。
- 点击当前歌曲也算手动重选；暂停、继续和输出重连保留顺序。故障恢复沿队列跳过不可播放项，每首最多尝试一次。
- 歌单删除条目时保留其余歌曲的随机顺序；新增条目加入末尾。显式限定的播放范围继续遵守原范围。
- 切回列表循环或单曲循环恢复来源排序，原歌单手动排序不会被随机播放改写。

终端原有 `queue.list` 返回实际顺序，新增 `queue.select` 和 `queue.move` 直接操作同一队列；`queue.play`、`player.next` 和 `player.previous` 使用同一宿主逻辑。没有新增必需插件能力，旧插件不需要重打包。CLI 和 Android 同样先生成队列再顺序播放；图形拖动只属于对应图形宿主。

## 动画与歌词流畅性

窗口最大化与还原直接执行系统切换，不播放客户区动画。容器展开/收回沿用可选风格 `morph` 配置，显式禁用仍优先。矩形、抛物线位移、二次缓动与圆角统一采样，快照有像素上限，完成或打断后释放。系统窗口状态、跨显示器与原生拖动仍由窗口管理器处理。

歌词以固定尺寸从播放栏朝向内容区的边缘垂直滑入歌词容器，保留背景页面标题；反向切换保留当前呈现帧。快照保持不透明直到同帧移除旧页底图并交接真实歌词，不在末段透出旧页。菜单、音量和日历也使用有限时长开合动画，支持外部点击与按钮再次点击关闭。普通页面继续沿用现有可选页面过渡配置。播放按钮增加悬停、按下、释放及取消反馈。

歌词逐字填色与平滑滚动共用屏幕渲染帧回调，避免多个定时器更新节奏不同。后端小幅采样抖动不会让填色倒退，主动跳转仍采用实际位置；滚动用连续速度曲线收敛到目标，重复的虚拟化尺寸通知不重启动画。仅更新已实现的歌词行，暂停且不滚动时停止请求帧，退出页面释放订阅。手动预览、触摸滚动、五秒恢复跟随和首尾居中保持有效。

相同歌词重载会创建新的 `LyricLine`，显示快照仍按内容相等复用旧行控件。当前行高亮使用相同的值比较语义，避免因对象引用改变而失去主题色；原文与翻译保持同步，逐字时间推进不变。`--lyric-highlight-only` 使用隔离 LRC 经过真实重载路径，检查保留的页面/行实例及实际绘制的主题色像素，可通过 `--style=<文件>` 验证外部方案。

系统减少动画偏好或 `NONET_REDUCED_MOTION=1` 会跳过空间动画，歌词时间与逐字填色仍准确跟随播放。

## 验证

```powershell
$env:NUGET_PACKAGES = Join-Path (Get-Location) '.packages'
dotnet run --project tests/NonetMusicPlayer.UiChecks.Desktop -c Release -- artifacts/queue-motion --queue-motion-only
```

检查随机完整循环、反向播放、手动重选、来源隔离、歌单删除、单曲循环、浮层关闭方式、快速开合、深浅主题、紧凑窗口及歌词转场资源清理。屏幕截图保存在上述 artifacts 目录；实际发布包的架构和 Windows 安装器按现有发布脚本另行验证。

`--track-reorder-only` 补充队列封面、鼠标/触摸/笔拖动、松手前容器让位、音频连续性、边缘滚动、失去捕获/关闭/Esc 回滚、非连续多选及系统 DragEnter/DragOver/Drop 后的数据库排序检查，支持同样的 `--style=<文件>` 参数验证外部方案。


本轮播放列表保存在窗口独立覆盖层，不属于方案可重建的 ShellLayout；反复导航、启停/重载方案不会丢失浮层。原生浮窗外部点击先结束旧弹层，再交给目标按钮；展开期间按钮带有 `popup-open` 类。

浮窗内的选项、菜单命令和嵌套下拉框继续接收完整指针事件。下拉框通过自身的展开状态关闭，保留模板绑定；选项选择、重复展开、再次点击和外部关闭使用同一控件状态。
