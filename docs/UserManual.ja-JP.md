# Nonet ユーザーマニュアル

デスクトップ版 0.4.0-beta.1。中国語・日本語・英語の画面で同じ機能を利用できます。

ボタンにマウスを重ねると、省略されていない名前と操作説明が表示されます。表示言語やボタンの状態に合わせて更新されます。省略された文字、読み取り専用のパス、選択項目にも完全な内容のヒントが表示され、長いヒントは折り返されます。

## はじめに

プラットフォームのフォルダー全体を保持してください。Windows 10 22H2 / Windows 11 x64 では Nonet.exe を起動します。macOS / Linux 版は実機検証待ちのプレリリースです。実行ファイルのフォルダーには書き込み権限が必要で、初期状態では隣の Data フォルダーにデータを保存します。

プレイリストを選択または作成し、追加アイコンかドロップで音楽を読み込みます。フォルダー内のサブフォルダーも対象です。他の画面へ音声ファイルをドロップする、またはOSから開く場合は一時再生となり、リストには自動追加しません。保存するにはお気に入りかプレイリストに追加してください。元の音楽ファイルは移動・削除しません。

タグと埋め込みジャケットを読み込み、ない場合は同じフォルダーのジャケットを探します。song.flac と同じ場所の song.lrc / song.txt は独立した歌詞フォルダーにコピーされます。

## ミュージックホームと再生

ミュージックはアルバム・アーティスト・プレイリストの小さなカードを表示するホームです。曲の一覧や分類の「すべて表示」から完全な一覧へ移動できます。最小化からの復帰やフォーカス復帰ではスクロール位置を保持します。明示的に曲一覧・履歴を開く場合は先頭、再生元プレイリストを開く場合のみ再生曲へ移動します。

シャッフルは既に選ばれた曲の確率を下げますが、ゼロにはしません。異なる曲が二曲以上あれば直前の曲を続けて選びません。重みの履歴はセッション内で保持し、手動の並び順を変更しません。

## ターミナルと独立 CLI

プラグインと設定の間のターミナルで、`nonet $ ` の後に `help` や `player pause` を入力します。セッション内では nonet を省略できます。`nonet clear` は表示のみを消去し、`nonet exit` はホームに戻ります。マウス・キー・プラグインと同じ状態を操作し、Logs に保存した同一の記録を表示します。入力コマンド自体はログにしません。確認は y + Enter または `-y`、取り消しは `-n`。設定 → ターミナルで不透明度、文字サイズ、履歴行数（既定 1000、最大 10000）、最低表示ログレベルを変更できます。ファイルのログレベルは変更しません。システム Shell は実行しません。

独立 CLI の実行名は `nonet` です。`publish/cli` の対応ディレクトリ全体をユーザー PATH に追加すると、CMD、PowerShell、Linux/macOS の端末から起動できます。GUI に依存せず、独立したデータと再生を使用します。再生にはローカル音声環境が必要です。PgUp でアプリの有界履歴を表示します。外部端末のバッファとフォントは端末側の設定に従います。デスクトップの Data は指定しないでください。再生を続けるには `--stay`。[CLI ガイド](CLI.md) と [コマンド一覧](COMMANDS.md) を参照してください。

任意の「精准歌词工具」プラグインは歌詞の「その他」メニューとサイドバーに入口を追加します。既定の現在の曲、または開始前に別の曲を選び、歌詞ファイルを選択して先頭から再生し、スペースで次の行の時刻を記録します。1 行目は 0、取り消しも可能です。全行完了後に LRC を保存して曲に関連付けます。元ファイルは変更しません。記録中の曲・モード変更は禁止し、曲の終わりで一時停止します。取り消し、ページ移動、プラグイン無効化は未保存の記録を破棄して制限を解除します。

## 曲の再生

検索では曲名、アーティスト、アルバム、音源を探せます。Enter、虫眼鏡、または入力欄から離れた時に検索を適用します。×で検索を消去します。曲をダブルクリックするか再生ボタンを押してください。

下部プレーヤーには前の曲、再生 / 一時停止、次の曲、再生モード、お気に入り、その他、音量、デスクトップ歌詞があります。進行バーはプレーヤーの上端いっぱいに表示され、クリックやドラッグで移動できます。モードはリストリピート、1曲リピート、シャッフルです。

赤いハートは固定プレイリスト「お気に入り」に登録済みを示します。再度押すと解除されます。音量、前回の曲と位置は保存しますが、起動時には自動再生しません。

再生できない曲は通知後に次の候補へ進み、リスト全体が失敗すると停止します。ファイル、形式、出力デバイス、音源設定を確認してください。Windows のタスクバーのプレビューには前の曲、再生 / 一時停止、次の曲があります。他のOSでは提供しません。

音声出力の変更や接続解除時は曲と位置を保持して一時停止し、利用可能な出力へ切り替えます。再生を押すと続きから再生します。出力がない場合は先に機器を接続してください。出力エラーで曲をスキップしません。同じユーザーはインストール先が異なっても一つのインスタンスだけ起動し、別の音声を開くと既存の画面に転送します。

再生バーへのドロップはプレイリスト画面でも常に一時再生です。タグ、ジャケット、歌詞を読み込み、最近の履歴には含めますが、ライブラリ、アルバム、アーティスト、統計には含めません。お気に入りやプレイリストへ追加した時点から通常の記録を始めます。一時再生専用のページは開きません。

## プレイリスト、アルバム、アーティスト

「お気に入り」は削除・名前変更できませんが、説明とジャケットは編集できます。他のプレイリストは作成、名前変更、編集、M3U の読み込み / 書き出し、削除ができます。削除しても元の音楽は残ります。

新しく追加した曲は上側に表示されます。曲をドラッグしてリスト内を並べ替え、サイドバーのプレイリストもドラッグで並べ替えられます。列見出しでは並べ替えません。再生中の表示は再生を開始したリストだけに表示し、曲の切り替えやリストへ戻った際にその曲へ移動します。

ライブラリ、最近の履歴、再生元でないプレイリストは、開くたびに先頭へ戻ります。同じ曲が別のプレイリストにあっても自動的にその曲へ移動しません。

行のクリックでは選択しません。「一括操作」を開くと曲の選択欄と3状態の全選択欄が表示されます。空欄は未選択、中間状態は一部選択、チェックは全選択です。全選択欄で選択 / 解除を行い、一括操作を終了すると選択を消去します。

曲とプレイリストには右クリックメニューがあり、タッチでは「その他」ボタンを利用できます。登録済み曲には「お気に入りから削除」を表示します。曲情報のタグと完全なパスは選択・コピーできますが、編集はできません。Windows では別のボタンでフォルダーを開いてファイルを選択できます。

アルバムとアーティストはタイルで表示します。「その他」でジャケットを変更または初期化できます。指定したジャケットと背景はアプリの管理データへコピーします。

画像を選ぶとトリミング画面が開きます。画像のドラッグ、ホイールやスライダーによる拡大、X・Y・一辺の正確なピクセル入力が可能です。適用すると320 × 320のジャケットを生成し、キャンセルは元の画像を保持します。背景とジャケットは20 MBまでで、デコード前にピクセル数も検証します。

## 歌詞とデスクトップ歌詞

プレーヤーのジャケットを押すと、左にジャケット、右に歌詞を配置した全幅の歌詞画面になります。再度押すと元の画面へ戻ります。時間付き歌詞は自動スクロールします。

ホイールは一行ずつ移動し、マウスやタッチのドラッグも可能です。操作終了時は中央の行に揃え、スクロールバーは表示しません。停止後に中央の行の横へ表示される再生ボタンを押すと、その時間へ移動します。画面を開き直すと現在の再生行に戻ります。歌詞のダブルクリックでは移動しません。「その他」から LRC / TXT を読み込めます。時間のないテキストは正確な行移動に対応しません。

デスクトップ歌詞は独立した透明ウィンドウです。メイン画面の最小化やトレイ表示で隠れず、再生バーのアイコンは復元した表示・ロック状態を反映します。原文と翻訳はテーマカラーを使い、ずれた影を描画しません。文字にホバーした時だけ枠を表示し、枠のない空白は背後へクリックを通します。解除後は四辺をドラッグして大きさを調整し、ボタン以外で移動できます。位置と大きさは保存され、マウス・タッチに対応します。設定 → 歌詞 → デスクトップ歌詞の文字サイズは初期値 28 px、範囲 14–48 px で、Enter またはフォーカスを外すと適用します。翻訳は原文の 68.75% です。翻訳がない場合は現在の原文のみを表示し、次の行を表示しません。ウィンドウや歌詞の長さで文字サイズは変化しません。長い行は現在の幅の中で横にスクロールし、ウィンドウを自動拡大しません。

統計のカレンダーでは年と月をリストから直接選べます。年の入力欄はなく、今年の前後100年（合計201年）の範囲でスクロールやキーボード選択ができます。範囲外の日付は選択できません。

アーティストとアルバムの右クリックメニュー、詳細画面のメニューでは、「既定のカバーに戻す」で曲から取得したカバーを使用し、「アプリの既定カバーを使用」でカバーがないときのアイコンを強制表示します。先頭の曲にカバーがない場合は他の曲を参照します。選択は再起動後も保持されます。

歌詞枠でロックすると移動・選択・終了を禁止し、全クリックを背後へ通します。再生バーの歌詞ボタンはロック解除に変わり、押すと表示を維持して解除します。閉じるには先に解除してください。Linux の透過入力には X11 Shape が必要で、未対応環境では完全なクリック透過を保証しません。空白の歌詞行は表示せず、翻訳の文字は原文より少し小さく表示します。

同じ時刻の行をまとめ、最初の行を原文、後の異なる行を翻訳として異なる文字サイズで表示します。一般的な二言語ファイルの規則であり、文字から言語は推測しません。複数の時刻とミリ秒オフセットに対応し、ホバーの背景は表示しません。

LRCは `[mm:ss]`、`[mm:ss.xx]`、`[mm:ss.xxx]`、`[mm:ss:xx]`、`[mm:ss;xx]` に対応します。小数は桁数で解釈し、`.12`・`:12`・`;12` は120ミリ秒、`.123` は123ミリ秒です。単語の時刻とオフセットでも同じ形式を使用できます。

## 設定、外観、ショートカット

言語変更はすぐに反映されます。初期テーマはシステムに従い、ライト / ダークも選べます。テーマカラーは選択やボタンの反応にも適用します。色相環、RGB、16進数で同じ色を指定できます。背景画像や対応するコントロールのスタイルも変更できます。

JSON レイアウトは提供される領域と必須の操作を配置します。編集前に保存し、外部エディターで編集・保存してから、設定で検証・再読み込みしてください。設定画面にはJSONの内容を表示しません。不正な設定では現在の表示を保持します。初期状態や有効なバックアップへ復元できます。必須操作は削除できず、スクリプトは実行しません。仕様は UI_LAYOUT.md を参照してください。

Windows のウィンドウ丸ボタンは左右を選べます。初期位置は macOS が左、Windows / Linux が右で、既存の設定は保持します。右側は最小化、最大化 / 元に戻す、閉じる。左側は閉じる、最小化、最大化 / 元に戻すで、ロゴ・名前・バージョンを中央に表示します。色と機能の対応は変わりません。「マイミュージック」と「プラグイン」は折りたたみ可能で、プレイリストも新規作成の右側のボタンで折りたたみでき、状態を保存します。ページ付きプラグインがなければプラグイン欄は非表示です。

設定は各分区を常に表示し、検索で項目を探せます。空白領域でもホイールでスクロールします。設定タイトル横のマニュアルボタンで本書を開きます。設定の初期化は確認が必要で、音楽、リスト、プラグイン、統計、保存先は保持します。

ナビゲーションの境界をドラッグして幅を変更します。再生バーの高さは、進行バーの下、再生操作の上にある中央の短いハンドルで変更します。進行バーの操作で高さは変わりません。マウスとタッチに対応し、サイズを保存します。カスタム領域は隣接配置に戻りますが、内部の配置とバックアップは保持します。再生速度とイコライザーは削除しました。

初期ウィンドウは画面の作業領域と表示倍率に合わせ、縦長や高DPIにも対応します。タイトルバーはタッチ・ペンで移動でき、最大化からの復元も可能です。タッチ用のサイズは自動調整し、手動の切替設定はありません。

背景はウィンドウ全体に表示します。タイトル、サイドバー、ページ、再生バーの不透明度を個別調整し、値を下げると背景がより見えます。文字やボタン自体の透明度は変わりません。全体の不透明度も別に設定できます。システムのフォント選択に加え、32 MBまでのTTF / OTF / TTCファイルを読み込んで即時使用できます。コピーはData/Fontsに保持し、OSへのインストールは不要です。既定のフォントを選ぶと元に戻ります。

最近の履歴は既定で1,000曲までです。0で無効にし、上限を減らすと古い履歴を除きますが、曲や統計は削除しません。

文字・数字の入力は Enter または他の場所を押してフォーカスを外した時に適用し、不正な値は反映しません。複数行では Ctrl+Enter またはフォーカス移動で適用し、Enter は改行です。スイッチ・選択・スライダーは即時反映します。プラグイン設定は「保存して閉じる」まで下書きです。

最小化時のメモリ最適化は既定で有効ですが、使用されなくなったオブジェクトだけを回収し、現在の画面、画像、スクロール位置を保持します。プロセスのワーキングセットを強制縮小せず、固定のメモリ上限は保証しません。閉じるボタンは既定でトレイへ戻り、設定で直接終了に変更できます。トレイメニューは開く・終了のみで、終了は完全に終了します。トレイ非対応時は通常終了します。

Windowsでは設定から音声形式を登録し、OSの既定アプリで本ソフトを選択します。移動後は再登録してください。macOSではFinderの情報画面で「このアプリケーションで開く → すべてを変更」を利用します。Linuxでは設定で登録後（xdg-utilsが必要）、ファイル管理の既定アプリを選択します。OSのアプリ登録情報のみシステム側へ書き込み、音楽とアプリデータは元の保存先に残ります。macOS / Linuxの連携は実機検証待ちです。

ショートカットは複数列で表示され、キーを記録、無効化、初期化して保存できます。変更は即時反映し、衝突や不正な組み合わせは保存しません。主な初期キーは空白で再生 / 一時停止、Ctrl+左右で前 / 次の曲、Ctrl+D でお気に入り、Ctrl+O で追加、Ctrl+L で検索、Ctrl+B で一括操作です。

入力欄、スライダー、選択欄、ゲームは固有のキー操作を維持します。タッチでは可視ボタンとメニューを利用でき、キーボードや右クリックは必須ではありません。

## 再生統計

上部の四つのカードは全体の統計を維持します。共通のカレンダーで日付を選び、その日・月・年の各パネルを同時に切り替えます。各期間の合計時間、再生数、最長時間・最多再生の曲とアーティストを表示します。一時停止、読み込み、時間移動、未保存の一時再生は聴取時間に含めません。統計はローカルに保存します。

## プラグイン

更新ボタンは設定とアンインストールの間にあります。GitHub からのインポートは元のリポジトリを確認し、ローカルのインポートは開発者が宣言したリポジトリを使います。同じ ID の新しいパッケージを読み込むと確認後に更新し、設定を保持します。同じバージョンは更新不要、旧バージョンでの上書きはできません。リポジトリ情報のない旧プラグインも使用でき、新しいローカルパッケージで更新できます。

プラグインセンターで .impp を選択・ドロップし、作者・種類・権限を確認後に有効にします。読み込める拡張子は .impp のみです。公開 GitHub Release のタグ・latest ページや .impp 添付URLからも取得でき、複数の時はOSに合うパッケージを選びます。上限128 MiBで、ソースコードは取得・実行しません。ごみ箱は先に無効化してから削除し、新規インストールは初期状態で無効です。

ダウンロードの進捗はメイン画面の右上の通知内に表示し、別ウィンドウは開きません。閉じるアイコンで中止できます。サイズが分かる場合は割合、不明な場合は待機アニメーションを表示します。ダウンロードと検証が完了すると進捗通知が消え、完了通知が約4秒後に自動で閉じます。完了後も情報と権限の確認が必要で、インストールや有効化は自動ではありません。

ページ付きプラグインはサイドバーの専用欄に表示します。ゲームはページを離れると停止します。デスクトップペットは定義に応じて浮動ウィンドウに表示し、無効化、削除、アプリ終了時にアニメーションとイベントを解放します。

ヘビゲームは矢印 / WASD、空白で一時停止、Rで再開します。音楽猫は再生、曲の切り替え、お気に入り、検索と曲変更のメッセージに対応します。

設定アイコンは plugin_config_schema.json から生成したアプリ内フォームを開きます。説明、スイッチ、選択、数値、リストと項目ごとの初期化に対応します。「保存して閉じる」で検証・適用し、「閉じる」は破棄します。フォーム構造は開発者のスキーマだけで定義します。スキーマが空または存在しない場合は設定項目なしと表示し、ユーザーによる項目の追加・削除・改名はできません。音源の「その他」からライブラリも読み込めます。既存のサーバーへ接続し、新しいサーバーは構築しません。パスワードと機密認証欄はセッションだけに保持し、再起動後には再入力が必要です。ネイティブ音源プロセスはサンドボックスではないため、信頼できる作者のみ利用してください。開発仕様は PLUGIN_DEVELOPMENT.md を参照してください。

歌詞プレビュー中も再生中の行の強調を維持し、操作しない時間が5秒続くと再生位置へ戻ります。長い原文・翻訳は同じ時刻の項目内で折り返し、「その他」から歌詞ファイルの場所を開けます（Windowsではファイルを選択）。

背景の不透明度は既定で50%です。背景もカバーと同じ切り抜き画面を使用し、左に画像、右にパラメーター、右下にキャンセル・保存を配置し、スクロールバーを使いません。背景はウィンドウまたは原画像の縦横比を選べます。

Windowsインストーラーは windows_installer にあります。書き込み可能なフォルダーを選択し、データはアプリの隣に保存します。アンインストールでも個人データは残し、音声の既定アプリは変更しません。ドロップ操作は固定で、再生バーでは一時再生、リストでは追加、他の画面ではリスト選択を案内します。右側ナビゲーションには内側の区切り線があり、上側再生バーの高さ調整は下端のハンドルを使用します。

## データ、バックアップ、復元

Data には音楽参照、プレイリスト、設定、進行、統計、ジャケット、歌詞、プラグイン、レイアウト、ログを保存します。実行ファイル横の bootstrap ファイルに独自ディレクトリーの選択を保存します。復元ファイルには音楽本体は含まれません。

背景を適用すると Artwork/Backgrounds は使用中の画像と直近のコピー2枚までを保持します。アプリを完全に終了すると使用中の1枚だけを保持し、背景がない場合は古い管理コピーを削除します。元画像、ジャケット、他のフォルダー、画像以外のファイルは削除しません。トレイへ隠す操作は完全終了ではありません。

設定でデータと復元先を選べます。移行は元データを保持し、有効になる時期を通知します。コピー中にプロセスを強制終了しないでください。ディレクトリー変更で再起動が必要な場合は画面の案内に従ってください。

有効なバックアップや旧 state.json を読み込めます。復元前に現在の状態を保管し、元の復元ファイルは保持します。自動再生せず、音楽ファイルも削除しません。Data 全体、元の音楽、外部歌詞フォルダーを別途バックアップしてください。アプリの移動だけでは外部音楽のパスは変わりません。

## 問題がある場合

- 曲を読めない場合は元パス、権限、ストレージ、ネットワーク、音源設定を確認します。
- ジャケットがない曲は埋め込み / 隣接画像がない可能性があり、各リストやタイルに指定できます。
- 歌詞が同期しない場合は時間付き LRC と時間補正を確認します。
- レイアウトに問題がある場合はライブラリを消去せず初期状態または有効な設定へ戻します。
- プラグイン障害はパッケージ版、OS入口、権限、設定を確認します。
- 診断ログは Data/Logs にあり、上限付きでローテーションします。一般的な認証欄はマスクしますが、共有前に個人情報を確認してください。

## 歌詞、保存と更新

行内の `[時刻]` と `<時刻>` を持つ拡張 LRC に対応し、両方の歌詞画面で字形の色を左から右へ進めます。文字全体の透明度は変化させません。翻訳に時刻があればその時刻、なければ原文の進行率を使います。通常の LRC は行単位の表示を維持します。再生スライダーのホバー・ドラッグ中はポインター位置の時刻を分:秒で表示します。ホバーは再生位置を変えず、離れると表示を隠します。フォーカス復帰時はすぐに再生行へ戻ります。埋め込み歌詞はタグから直接読み、別ファイルを生成しません。手動指定した歌詞を優先します。

最近の履歴からの削除は履歴のみです。アルバムとアーティストは削除不可の分類です。最後のプレイリスト参照を除いた曲は管理データのみを整理し、元の音声・歌詞は削除しません。全曲画面で確認付き削除を行うと全プレイリストの参照を除きます。M3U 名の接頭辞は翻訳された「プレイリスト」です。

デスクトップは Data/library.db（SQLite）へ増分保存し、一貫したバックアップを作成します。旧 state.json は移行後も保持します。CLI は独立したソース生成 JSON を使い、既定で文字 TUI を表示します。Tab / Shift+Tab でページを切替、矢印で選択、Enter で実行、Space で再生・一時停止します。F1–F7 は使いません。コマンド入力はプラグインとヘルプの間の「ターミナル」だけです。上下矢印で履歴、PageUp / PageDown で出力を表示し、Ctrl+L で消去します。設定ページはキーボードで編集できます。Ctrl+K で全操作と引数フォームを開き、Tab で項目を移動、Ctrl+N で繰り返し引数を追加、Enter で実行、Esc で中止します。危険操作は既定で中止、Y で承認します。Ctrl+D で終了します。詳しくは CLI.md を参照してください。`--repl` は連続プロンプト、`--no-tui` は行モードです。

設定末尾の「情報」にはバージョン、更新確認とリポジトリリンクがあります。起動時も確認し、対応する新しい Release があると New から変更履歴、ダウンロード、更新して再起動へ進めます。終了後にアプリだけを置換し、失敗時は復元します。データは置換しません。https://github.com/hhwfsl/NonetMusicPlayer が未作成、または対応 Release がない場合は更新しません。公開用実行ファイルと書き込み可能なインストール先が必要です。

プラグインのアンインストールは先に無効化し、本体を削除するか Plugins/Retained に保持するか選べます。音源は無効化・アンインストール・終了のコールバックを宣言でき、宣言式 UI のリソースは宿主が解放します。

プレリリースのため問題が残る場合があります。バックアップを保持し、不明なネイティブプラグインを実行しないでください。

「先頭に戻る」は設定検索のクリアボタンの右、曲・履歴・アルバム/アーティスト内の一覧では一括選択ボタンの右にあるアイコンです。再生や選択を変えずに表示位置のみ戻します。
