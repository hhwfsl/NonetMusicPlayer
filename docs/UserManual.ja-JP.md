# Nonet ユーザーガイド

> デスクトップ版 0.4.0-beta.53 対応。

## 音楽を取り込んで再生する

1. サイドバーのプレイリストから「お気に入り」を選ぶか、新しいプレイリストを作成します。
2. プレイリストのツールバーから曲やフォルダーを追加します。音楽ファイルをプレイリストにドロップすることもできます。Nonet は元のファイルを参照するので、移動や削除に注意してください。
3. 曲をダブルクリックして再生します。プレーヤーバーで一時停止、曲送り、音量調整、再生位置の変更ができます。バーに音楽ファイルをドロップすると一時再生し、お気に入りやプレイリストに追加するとライブラリに残せます。

## 曲を探す・プレイリストを整理する

- 「音楽」ページから曲、アルバム、アーティストの一覧を開けます。ページ内の検索欄で一覧を絞り込みます。音楽サービスのプラグインを有効にした場合は、右上の検索欄でサービスを選んで検索できます。
- 曲をドラッグするとプレイリスト内の順番が変わります。サイドバーのプレイリストもドラッグで並べ替えられます。曲のメニューから詳細の表示、別のプレイリストへの追加、現在のプレイリストからの削除ができます。
- プレイリストのメニューで名前、説明、カバーを編集したり、M3U を入出力したりできます。複数の曲をまとめて操作するには、ツールバーで一括操作を開きます。

## 再生キュー

プレーヤーバーのデスクトップ歌詞ボタンの隣にあるキューボタンで再生順を確認できます。曲を選ぶと再生し、ドラッグすると順番が変わります。同じボタンを押すか、パネルの外をクリックするか、Esc キーを押すと閉じます。

再生モードボタンでリストリピート、1 曲リピート、シャッフルを切り替えます。シャッフルは作成したキューの順に再生します。曲を手動で選ぶと、その曲を先頭に並べ直します。

## 歌詞とデスクトップ歌詞

- プレーヤーバーのカバーをクリックして歌詞ページを開きます。もう一度クリックすると元のページに戻ります。スクロールで歌詞を確認し、行の横にある再生ボタンでその位置へ移動できます。
- 音楽ファイルと同名の .lrc を同じ場所に置いて取り込むか、プレーヤーバーのメニューから現在の曲に LRC / TXT を取り込みます。歌詞の保存先と時間補正は設定から変更できます。
- デスクトップ歌詞ボタンで独立した歌詞ウィンドウを開きます。歌詞にポインターを重ねると、移動、サイズ変更、ロックができます。ロック後はプレーヤーバーで解除します。

## プラグインとデバイス間の共有

- プラグインセンターで .impp ファイルを取り込むか、公開 GitHub Release のリンクを指定します。配布元と権限を確認して有効にし、歯車ボタンから設定します。ページを持つプラグインはサイドバーに表示されます。購読したプレイリストの曲は、音楽サービス側で編集すると同期されます。
- 同じローカルネットワーク内の 2 台でデバイス共有ページを開きます。一方で共有を有効にして招待をコピーし、もう一方で貼り付けて接続します。招待元で承認すると相手の曲を再生できます。曲を提供するデバイスはオンラインのままにします。

## 設定、再生統計、アップデート

- 設定で項目を検索できます。「外観」でテーマ、フォント、背景を、「ショートカット」でキー操作を変更できます。レイアウト設定で既定のウィンドウサイズに戻すと、ウィンドウが中央に配置されます。
- 再生統計で再生時間を確認できます。カレンダーで日付を選ぶと、その日、月、年の集計が表示されます。
- 設定からライブラリのバックアップと復元ができます。別の端末に移すときは、元の音楽ファイルも移してください。デスクトップ版と独立した CLI のデータフォルダーは別です。
- 設定の「情報」でバージョンの確認と更新チェックができます。Nonet の横に New が表示されたら選択してダウンロードします。旧版でチェックできない場合は、リポジトリのリンクから GitHub Releases を開いて取得できます。
- キーボードで操作したり、コマンドをまとめて実行したりするには、サイドバーのターミナルを開いて nonet help を入力します。
