# Nonet 使用手册

适用于桌面版 0.4.0-beta.1。中文、日语与英语界面提供同样的功能。

鼠标悬停在按钮上可查看完整名称及已有操作说明，名称随当前语言和按钮状态更新。被省略的文字、只读路径和下拉选择也提供完整提示；长提示自动换行，不需要扩大窗口即可查看。

## 开始使用

保留完整平台文件夹并运行程序。Windows 需要 Windows 10 22H2 或 Windows 11 x64；macOS、Linux 版本仍属待实机验证的预发布。程序目录必须可写，默认数据保存在程序旁的 Data。

先选择或新建歌单，用工具栏的添加音乐 / 文件夹图标导入，悬停可查看说明。拖入歌单也会添加至该歌单。拖入播放栏或通过系统打开的音频，仅临时播放，不自动加入歌单；点击喜欢或添加到歌单才会保存其引用。文件夹必须在歌单中导入。音乐文件保持原位置，移除歌曲不删除原文件。

导入时读取标签和内嵌封面；缺少内嵌封面时查找同目录封面。识别同名 LRC / TXT 并复制至独立歌词目录。例如 song.flac 与 song.lrc 放在一起，导入 song.flac 后即可显示歌词。

## 音乐主页与播放

侧栏“音乐”是主页，以较小卡片展示专辑和艺术家。从“浏览歌曲”进入所有歌单仍在引用的歌曲列表，从分类“查看全部”进入虚拟化的完整专辑或艺术家页面。专辑和艺术家不再单独占用侧栏入口。最小化恢复及失焦后恢复焦点保留原滚动位置；主动进入歌曲列表和最近播放仍置顶，主动进入播放来源歌单定位当前歌曲。侧栏删除其他歌单不会跳离正在使用的终端、设置等页面。

随机模式采用历史降权：已经随机命中过的歌曲仍可能再出现，但概率降低；队列至少有两首不同歌曲时，随机下一首不会是刚刚播放的歌曲。随机权重保留在当前会话，不改变歌单手动排序。

搜索框查找歌曲、艺术家、专辑和音源。输入后按回车、点击放大镜或离开输入框时搜索；叉号清空搜索。双击歌曲或点击歌曲播放按钮开始播放。底部播放栏提供上一首、播放 / 暂停、下一首、模式、喜欢、更多、音量和桌面歌词。

播放进度条位于播放栏上沿，点击或拖动跳转。模式仅有列表循环、单曲循环和随机播放。红色心形表示歌曲已加入“我喜欢”；再次点击移除。音量按钮打开竖向调节，静音和音量状态会保存。

无法播放的文件会显示提示并尝试下一首；当前列表全部不可播放时停止。请检查原文件是否存在、编码是否受支持、输出设备是否可用。服务器歌曲还需检查音源插件与配置。

Windows 任务栏预览提供上一首、播放 / 暂停、下一首。macOS、Linux 不提供此功能。

默认播放栏为 96 px 高；触摸模式保留较大的操作区域。进度圆点在两端完整可见。播放栏“更多”提供歌曲操作，不提供倍速或均衡器。

切换输出设备、拔出耳机或默认输出变更时，播放器暂停并保留歌曲和进度，自动连接可用输出。点击继续从原位置播放；没有输出时先连接设备。输出错误与解码错误分别处理，不因输出失效而跳过歌曲。

同一用户只能打开一个实例；再次启动或用系统打开音频，会激活现有窗口并切换到该音频。直接把外部文件拖到播放栏也会临时播放，即使当前在歌单页面。临时音频提取标签、封面和歌词，加入最近播放，但不进入音乐库、专辑、艺术家或听歌统计；收藏或添加到歌单后，从添加时起按正常歌曲记录。不会打开额外的临时播放页面。

## 内置终端与 CLI

侧栏插件中心下方、设置上方的“终端”直接控制当前播放器。在 `nonet $ ` 后输入命令并回车，可省略 `nonet`（例如 `player pause`、`help`），例如 `nonet help`、`nonet player pause`、`nonet player seek 60`、`nonet settings set volume 50`。没有单独输入框。鼠标、快捷键、插件与终端共用状态，完成事务写入 Logs 后显示同一日志记录；输入命令本身不作日志。上/下键调取命令历史，配置输入不回显或留历史；`nonet clear` / Ctrl+L 只清显示。设置 → 终端可调不透明度、字体、历史行数（默认 1000，最多 10000）及最低显示日志等级，磁盘等级固定不受影响。此终端不执行系统 Shell。

危险操作在终端输入 y + Enter 确认，或使用 `-y`；`-n` 取消。移除歌曲不删除原文件。`nonet window close` 遵循托盘设置，`nonet app exit` 完全退出；无分类的 `nonet exit` 返回主页。

独立 CLI 的程序名为 `nonet`，在 `publish/cli`。将整个发布目录加入用户 PATH 后，可从 CMD、PowerShell、Linux/macOS 终端输入 `nonet` 启动。使用独立 Data 和播放会话，不含窗口；实际发声仍需本机音频设备。PgUp 回看应用保留的历史，外层终端自身的缓存和字体由其设置管理。不要指定桌面版数据目录。详见 [CLI 手册](CLI.md) 和 [命令参考](COMMANDS.md)。

精准歌词工具是可选插件。导入并启用后从歌词“更多”或插件侧栏进入。默认当前歌曲，也可在开始前改选标注歌曲；选择歌词文件、开始从头播放，首行时间为 0，空格依次标注下一行；可撤销，全部完成后保存并关联歌曲。标注期间不能切歌或改模式，曲终暂停。取消、离页或禁用插件会放弃未保存标注并解除限制；原始输入文件不改变。

## 系统音频关联

Windows：设置 → 播放与声音 → 设置默认播放器，确认后注册支持格式并打开系统设置，再选择本软件。不会直接覆盖已有默认应用，移动软件目录后需重新注册。

macOS：首次打开 `.app` 后，在 Finder 的音频文件“显示简介 → 打开方式”中选择本软件，再使用“全部更改”。Linux：设置中注册音频打开方式（需要 xdg-utils），随后在文件管理器选择默认应用。系统关联会写入系统维护的应用列表；音乐和播放器数据仍保存在原有目录。macOS / Linux 的关联仍需实机验证。

## 歌单、专辑与艺术家

“我喜欢”是不可删除或改名的固定歌单，仍可修改描述和封面。普通歌单可创建、改名、编辑、导入 / 导出 M3U 和删除。删除歌单不删除音乐文件。

新添加歌曲显示在歌单前面；拖动歌曲调整顺序，也可拖动左侧歌单调整栏目顺序。歌单中列标题不用于排序。播放高亮只出现在开始播放的来源歌单；切歌及再次进入来源歌单会定位当前歌曲。

音乐库和最近播放每次进入均置顶，不定位当前歌曲。其他歌单也置顶；只有当前播放歌曲的来源歌单会定位到该歌曲，同一歌曲在别的歌单中不会触发定位。

歌曲行单击不会选中。点击“批量操作”后显示选择框与三态全选框：空框表示未选，实心中间态表示部分选择，勾选表示全选。再次点击全选框取消全选。只有点歌曲前面的框才能选择；退出批量模式会清空选择。

歌曲、歌单封面区域和左侧歌单均可打开右键菜单，触摸用户可使用可见“更多”按钮。已喜欢歌曲的菜单显示“从我喜欢中移除”。歌曲信息显示封面、标签及完整路径，文字均可选中复制但不能编辑；Windows 可用独立按钮打开所在位置并定位文件。

专辑和艺术家使用方块展示。右键方块或进入详情页的“更多”可更换封面；“恢复默认封面”恢复该分类歌曲中解析出的封面，第一首歌曲没有封面时继续查找其余歌曲；“设置为软件默认封面”强制使用无封面时的图标。两种默认方式独立保存。栏目封面、歌单封面和背景会复制为播放器托管数据，不依赖原图片留在原处。

选择封面后，在裁剪窗口拖动图片选择保留区域，用滚轮或缩放滑块调整大小，也可输入 X、Y 和正方形边长的精确像素。确认后生成 320 × 320 封面；取消不替换当前封面。背景和封面图片上限为 20 MB，同时校验解码前的像素尺寸。

普通歌单未指定封面时使用排序第一首歌曲的封面，该曲没有封面则使用默认图。专辑与艺术家是标签汇总，不能直接导入或删除歌曲；应在歌单中添加或移除。最近播放只能移出历史，不影响歌单。某曲失去所有歌单引用时，软件移除自己的元数据、封面和歌词副本，不删除原音频或原歌词。浏览歌曲中的删除需要确认，并移除该曲的所有歌单引用。M3U 默认文件名为本地化的“歌单_歌单名”。歌曲和分类方块采用视口虚拟化，大列表不会一次创建所有歌曲块。

## 歌词与桌面歌词

点击播放栏封面展开全宽歌词页面，左侧展示封面，右侧展示歌词；再次点击封面返回原页面。歌词随播放自动滚动，不需要启用额外设置。

用滚轮每次预览上一句或下一句；也可按住鼠标或手指上下拖动，松开后对齐到居中歌词，不停留在两句之间。页面不显示滚动条。停止滚动后，居中歌词旁出现播放按钮；点击它跳到该行时间。预览以外不显示此按钮，也不通过双击歌词跳转。重新进入页面回到当前播放行。预览不改变当前播放行的高亮；停止操作 5 秒后恢复跟随。长原文和译文自动换行，仍属于同一句歌词。页面“更多”提供导入 LRC / TXT 和打开歌词文件位置，Windows 会选中该文件；歌词设置可调整目录与时间偏移。

播放栏的桌面歌词按钮显示或隐藏透明独立窗口，启动时图标反映恢复的状态，主窗口最小化或回到托盘时歌词继续显示。默认位于屏幕底部，原文和译文即时跟随主题色，不绘制偏移阴影。悬停歌词文字才显示框和按钮，离开后只保留文字；隐藏框时，文字外的空白点击穿透到后方应用。解锁且框显示后，拖动四边可调整宽高，不提供右下角联合缩放区；按钮和边缘调整区域以外均可拖动窗口，支持鼠标与触摸。松开后保存位置和尺寸。设置 → 歌词 → 桌面歌词字号默认为 28 px，可设置 14–48 px，回车或失去焦点后应用；翻译固定为原文字号的 68.75%。无翻译时仅显示当前句原文，不显示下一句。窗口尺寸、短句或长句都不会改变字号。长句超过现有宽度时自动横向滚动，不自动扩大窗口；仍可手动调整窗口大小。

点击歌词框的锁定按钮后，歌词不接收点击，不能移动或关闭。播放栏桌面歌词按钮变为解锁图标，点击仅解锁，不隐藏歌词；解锁后可以关闭。Linux 的点击穿透需要 X11 Shape 支持；其他不支持的平台仍可显示歌词，但输入穿透不保证可用。没有时间标签的 TXT 可显示文本，但不能按行精确定位。

LRC 支持 `[mm:ss]`、`[mm:ss.xx]`、`[mm:ss.xxx]`、`[mm:ss:xx]` 和 `[mm:ss;xx]`。小数部分按位数解释，例如 `.12` / `:12` / `;12` 均为 120 毫秒，`.123` 为 123 毫秒。支持同一行多个时间标签及 `[offset:毫秒]`。同时间戳的不同文本作为原文与翻译共同显示，先出现的行为原文，后续行为翻译；这是常见双语文件约定，不通过语言字符猜测。空白行不显示，译文字号略小于原文，歌词悬停不显示背景。无时间标签的文本不提供自动定位。

支持行内 `[时间]` 和 `<时间>` 的逐字 / 逐词 LRC。检测到字词时间后，歌词页与桌面歌词按时间从左到右推进字形内的颜色，不对整字做透明度渐变。翻译有自己的时间标签时采用自身时间，否则按原文完成比例推进；普通逐行文件维持逐行显示。桌面歌词不绘制偏移阴影。悬停或拖动播放进度条时，浮层显示指针所在位置的分钟:秒；悬停不改变进度，指针离开后隐藏。重新获得焦点时立即定位播放行，不等待预览超时。内嵌歌词直接读取音乐标签，不另外生成 LRC 文件；手动指定歌词优先于内嵌歌词。

## 外观、语言与布局

设置内选择简体中文、日本語或 English，切换即时生效。默认主题跟随系统，也可固定浅色或深色。主题色应用于按钮交互、选中、高亮及主要控件；色轮、RGB 和十六进制输入提供同一颜色的多种选择方式。

界面字体可从系统已安装字体选择，也可导入 TTF / OTF / TTC 文件，立即生效；无需向系统安装。字体文件上限 32 MB，副本保存在 Data/Fonts，原文件移动后仍可用。无法显示的字符使用后备字体，选择默认字体可恢复。

背景图片覆盖整个应用，包括标题、导航、页面与播放栏；默认各区域使用相同的背景遮罩。背景图片不透明度控制照片强度，四个区域的不透明度分别控制区域遮罩，区域值越低越能看到照片；不影响文字、图标和按钮本身的清晰度。界面不透明度仍控制整个窗口。自定义布局使用外部 JSON 文件：先导出或保存现有布局，在自己的编辑器修改，再在设置中校验与重新加载；设置不展示 JSON 内容。布局不能移除必要播放控件，也不执行脚本。详细字段见 UI_LAYOUT.md。

导航宽度通过导航与内容的可见分割线调整，左右位置均有内侧分割线。播放栏在底部时，高度通过进度条下方、三个播放按钮上方的中央短手柄调整；放到顶部时手柄镜像移到底部，不通过整条边缘调整，以免与进度跳转冲突。鼠标或手指按住拖动，松开后保存。如使用自定义工作区坐标，调整会回到相邻区域排布，嵌套播放器配置保留，上一份配置备份可恢复。

初始窗口按屏幕工作区和显示缩放选择尺寸，兼顾横屏、竖屏与超宽屏。触摸或触控笔可在标题栏拖窗，最大化状态下拖动还原；触摸操作目标自动适配，不提供手动触摸优化开关。

Windows 可选择窗口圆点位于左上角或右上角。macOS 初始在左侧，Windows / Linux 初始在右侧。右侧顺序为最小化、最大化 / 还原、关闭；左侧顺序为关闭、最小化、最大化 / 还原，此时图标、名称和版本居中。颜色始终对应功能，已有位置偏好保留。

“我的音乐”和“插件”栏目可收起，歌单标题右侧的收起按钮可折叠歌单列表，状态会自动保存；没有可用插件页时不显示插件栏目。

## 设置与快捷键

设置搜索快速查找设置项，所有分区直接显示。标题右侧的使用手册按钮打开本手册。空白区域也可用滚轮滚动，路径项可点击打开目录。数据与恢复中的“恢复默认设置”需要再次确认，仅重置偏好与布局，保留音乐、歌单、插件、统计和存放目录。

快捷键编辑区按多列展示。点击录入按钮并按组合键，保存后即时生效；可清空禁用某操作，也可恢复默认。冲突或无效按键会阻止保存。默认常用按键：空格播放 / 暂停、Ctrl+左 / 右上一首 / 下一首、Ctrl+D 喜欢、Ctrl+O 添加音乐、Ctrl+L 搜索、Ctrl+B 批量模式。

播放与声音 → 最近播放保留上限默认 1000 首。设为 0 不保留；降低上限会移除较早记录，不删除音乐文件或听歌统计。

文本与数字输入在回车或点击其他位置时应用并失去焦点；非法内容不应用。多行文本使用 Ctrl+回车或离开输入框，普通回车换行。开关、选择和滑块即时应用。插件表单内的输入只修改草稿，必须“保存并关闭”才应用到插件。

“最小化时优化内存”默认开启，仅尝试回收已经不再使用的对象，不销毁当前页面、图片和滚动状态，也不强制裁剪进程工作集。该操作不保证固定内存数值。“点击关闭按钮”默认回到托盘，可改为直接关闭。托盘菜单只有“打开软件”和“关闭软件”，后者完全退出；系统不支持托盘时按正常退出处理。

文本输入、滑块、选择框和插件游戏保留其本身需要的按键；例如输入框中的空格不会暂停音乐。触摸操作可使用播放栏、歌曲功能按钮与更多菜单，无需依赖键盘或右键。

## 听歌统计

顶部四个卡片展示总体统计。日历顶部直接从下拉列表选择年份和月份，无需输入或逐月跳转。年份限定为今年前后各 100 年，共 201 年，下拉列表支持滚动和键盘选择。选择一天后，下方每日、每月、每年同时切换到该日及其所属月份、年份，展示各周期总时长、播放次数、聆听最长 / 播放最多的歌曲与艺术家。暂停、载入、手动跳转及未保存的临时播放不计入。统计在本地保存，不上传服务器。

## 插件

在插件中心选择或拖入 .impp 文件，确认作者、类型和权限，然后用开关启用。只接受 .impp 后缀。也可点击 GitHub Release 导入，填写公开仓库 Release 标签页、latest 页或 .impp 附件链接；有多个包时选择对应平台。只下载插件附件，不拉取或执行仓库源码；附件上限 128 MiB。卡片展示名称、作者、版本、类型及描述；垃圾桶按钮卸载，自动先关闭插件。安装后默认禁用。

下载进度在主窗口右上方的提示框中显示，不打开独立窗口，可点击叉号取消。已知附件大小时显示百分比，否则显示等待动画。下载及校验完成后进度框消失，再出现“插件下载完成”提醒，约 4 秒后自动关闭。下载完成不代表已安装或启用，仍需确认插件信息和权限。

带页面的插件启用后出现在侧栏“插件”栏目。小游戏离开页面后停止计时；桌宠根据插件定义显示浮动窗口，停用、卸载或关闭播放器时停止动画和事件。

插件卡片的配置图标打开应用内弹层，依据作者提供的 plugin_config_schema.json 展示说明、开关、枚举、数字、列表等，单项恢复图标重置默认值。“保存并关闭”验证并应用，“关闭”放弃未保存修改。表单结构只由开发者的规范定义，用户不能新增、删除或改名字段；规范缺失或为空时显示“无配置”。音源插件“更多”还可读取曲库。插件连接已有服务器，播放器不建立服务器。密码及敏感认证字段只在当前会话保留，重启后需重新填写。独立进程音源具有本机程序权限，不是沙箱，只安装可信来源。

贪吃蛇示例使用方向键 / WASD、空格暂停和 R 重开。音乐猫示例可切歌、播放暂停、喜欢、搜索及显示歌曲变化；其受限主机动作必须声明权限。插件开发接口见 PLUGIN_DEVELOPMENT.md。

背景图片默认不透明度为 50%，已有自定义值保留。背景选择支持窗口比例或原图比例裁剪，封面仍为正方形；裁剪窗口左侧调整图片，右侧输入参数和缩放，右下角取消 / 保存，页面不使用滚动条。拖放行为固定，不提供自动播放开关：播放栏临时播放，歌单添加，其他页面提示选择歌单。

Windows 安装版在 windows_installer 中。选择当前用户可写的目录，安装向导可创建快捷方式；数据默认位于程序旁的 Data，卸载保留数据，重新安装到同目录可继续使用。默认音频应用仍由系统设置中的用户选择决定。

## 数据、备份与恢复

桌面曲库保存到 Data/library.db（SQLite），进度增量保存；首次启动会从旧 state.json 迁移并保留旧文件。备份使用一致性数据库副本，也接受旧 JSON 恢复文件。CLI 仍使用自己独立的源生成 JSON 状态，不能混用两种数据目录。

## 软件更新

设置最下面的“关于”显示版本、检查更新和仓库链接；启动也会后台检查。发现对应系统的新 Release 后，标题栏版本旁显示 New，点击查看更新日志并下载，进度显示在应用内提示中。完成后按“重启完成更新”，软件退出、替换程序并重新启动，数据不参与替换，失败时回滚。更新仓库为 https://github.com/hhwfsl/NonetMusicPlayer；仓库不存在或尚无适配的 Release 时不会更新。必须使用发布版并确保安装目录可写。

CLI 默认提供字符 TUI：Tab / Shift+Tab 切页，方向键选择，Enter 打开或执行，空格播放暂停，不使用 F1–F7。终端位于插件与帮助之间，仅终端页输入命令，上下箭头恢复命令历史，PageUp / PageDown 浏览输出，Ctrl+L 清屏。设置页可直接编辑配置；Ctrl+K 打开全部可用操作的选择列表和参数表单，不必手写命令。表单以 Tab 换字段、Ctrl+N 增加可重复参数、Enter 执行、Esc 取消；危险操作默认取消，按 Y 确认。Ctrl+D 退出 TUI。`--repl` 是连续命令模式，管道和 `--no-tui` 使用逐行模式。完整键盘说明见 CLI.md。

卸载插件前先停用，可选择删除文件或保留到 Plugins/Retained；原音乐不受影响。音源插件可声明禁用、卸载和关闭回调，声明式页面资源由宿主统一释放。

## 存放与迁移

Data 保存音乐库引用、歌单、设置、进度、统计、封面、歌词、插件、布局及后台日志；播放器旁的 bootstrap 文件记录自定义目录。音乐本体不在恢复文件内。复制播放器及 Data 时，外部音乐原路径仍需可访问。

可在设置选择数据目录与恢复文件目录。迁移会保留旧数据并提示生效时机；复制期间请勿强制结束程序。只在目录变更需要重启时，按界面提示完成重启。

应用新背景后，`Artwork/Backgrounds` 最多保留当前图片和两张近期副本。通过托盘“关闭软件”或直接退出时，只保留当前背景；没有应用背景时清理旧副本。清理只处理播放器托管目录中的图片，不删除原图片、封面及其他目录的文件。回到托盘不会触发退出清理。

恢复入口支持有效备份和旧版 state.json。恢复前归档当前状态，原恢复文件保留。恢复不会自动开始播放，也不删除音乐原文件。修改数据前建议另外备份整个 Data，以及必要的外部音乐与自定义歌词目录。

## 故障处理

- 歌曲消失或无法读取：检查原路径、权限、存储设备和网络连接，必要时重新导入。
- 没有封面：文件可能没有内嵌或邻接封面；可为歌单 / 专辑 / 艺术家指定封面。
- 没有同步歌词：导入带时间标签的 LRC，检查歌词偏移和当前曲目匹配。
- 插件无法启用：检查包版本、对应平台入口、声明权限和插件配置；禁用后可重新安装。
- 布局不可用：在设置恢复默认布局或有效备份，不需清空音乐库。
- 需要排查错误：后台日志位于配置数据目录的 Logs，日志有轮转上限并对常见凭据字段脱敏；分享前仍应检查是否含个人信息。

预发布版本仍可能有缺陷。保留备份，并避免安装不可信的独立进程插件。

设置搜索框的清除按钮右侧提供“回到顶部”；歌曲列表、最近播放、专辑/艺术家内的列表将该按钮放在批量操作按钮右侧，均为带提示的图标按钮。回顶只改变视口，不改变播放与选中状态。
