# Nonet 使用手册

> 适用于桌面版 0.4.0-beta.53。

## 导入和播放

1. 在侧栏打开「歌单」，选择「我喜欢」或新建一个歌单。
2. 打开歌单，在工具栏点击「添加音乐」「添加文件夹」，也可以把文件拖进歌单。Nonet 会引用原文件，请让文件保持可访问。
3. 双击歌曲开始播放。用播放栏暂停、切歌、调音量，或点击进度条跳转。把外部音频拖到播放栏可以临时播放，点心形或从「更多」加入歌单后便可留在曲库。

## 查找歌曲和整理歌单

- 在「音乐」主页进入完整歌曲、专辑与艺术家列表。用页面搜索框查找当前列表；安装并启用音源插件后，可在右上角选择音乐平台再搜索。
- 在歌单内拖动歌曲排序，也可以拖动侧栏里的歌单重排。歌曲的「更多」菜单可查看信息、添加到其他歌单或从当前歌单移除。
- 从歌单的「更多」菜单修改名称、描述和封面，或导入、导出 M3U。需要一次处理多首歌曲时，先打开工具栏的「批量操作」。

## 播放列表

点击播放栏上桌面歌词右侧的「播放列表」，查看即将播放的顺序。点一首歌就能播放，拖动曲目可以调整顺序。再次点击按钮、点击浮层外或按 Esc 收起。

用播放模式按钮切换列表循环、单曲循环和随机。随机模式会洗牌并按播放列表顺序播，手动选歌会以该歌为起点重新洗牌。

## 歌词与桌面歌词

- 点击播放栏封面展开歌词页，再点一次返回。歌词跟随进度滚动；可上下滚动预览歌词，点预览行旁的播放按钮跳到该处。
- 将同名 .lrc 放在音频旁再导入，或从播放栏「更多」为当前歌曲导入 LRC / TXT。歌词设置可调整目录和时间偏移。
- 点击播放栏的桌面歌词图标显示独立歌词窗口。悬停歌词可拖动、调整尺寸或锁定。锁定后，先点播放栏的解锁图标即可重新操作。

## 插件和设备互听

- 在「插件中心」导入 .impp 或填写公开 GitHub Release 链接。确认来源和权限后启用，点击齿轮配置。带页面的插件可从侧栏打开。订阅音乐平台的歌单后，曲目在源平台修改，Nonet 会同步。
- 在同一局域网内，两台设备打开「设备互听」。一端开启共享并复制邀请，另一端粘贴连接，发出邀请的一端确认。连接后可浏览、播放对方曲库。播放对方设备上的歌曲时，请保持该设备在线。

## 设置、统计和更新

- 在「设置」里搜索要调整的选项。「外观」可更换主题、字体和背景，「快捷键」可修改常用按键。「布局 → 恢复默认窗口大小」可恢复尺寸并居中。
- 在「听歌统计」查看播放时长。用日历选择日期可查看对应日期、月份和年份的记录。
- 在设置中备份或恢复曲库。更换设备时，还需迁移原音乐文件；桌面与独立 CLI 使用各自的数据目录。
- 在「设置 → 关于」查看版本并检查更新。软件名旁出现 New 时可点击下载。旧版若无法检查，可从「关于」的仓库链接打开 GitHub Releases 下载对应版本。
- 需要键盘操作或批处理时，打开侧栏「终端」，输入 nonet help 查看可用命令。
