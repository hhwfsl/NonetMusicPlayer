# 桌面发行验证

版本：Nonet 0.4.0-beta.43。插件开发 SDK：4.16.0；程序集兼容基线：4.0.0.0。

## 2026-11-03 桌面 0.4.0-beta.43

本次正式发布仅提升桌面版本；CLI 0.4.0-beta.32、Android 0.3.0-beta.10 与插件 SDK 4.16.0 保持不变。GitHub 源码使用以公开 main 为父提交的干净快照，不上传本地旧开发历史、私人插件、样式项目、使用数据或构建归档；Android 保持已公开内容。

- 下拉框回归先复现指针选择失败，再验证修复后连续选项选择、重新展开、再次点击收回、外部点击传递、嵌套浮窗选择及菜单命令。内部事件沿可视树和 Popup.PlacementTarget 判断归属，关闭通过 ComboBox 自身状态完成，保留模板绑定。
- `--surface-revision-only` 在原版与显式传入的清蓝 2.0.8 下检查同步最大化/还原、背景标题保留、播放栏边缘垂直歌词转场、同帧交接、队列重组后重复打开、快速开合、浮窗选中态和日历关闭。该专项同时运行下拉框输入回归。
- `--queue-motion-only` 和 `--desktop-revision-only` 通过随机完整循环、上一首、手动重选、来源隔离、歌单编辑、故障跳过、歌词更新、SQLite 和离线更新包校验。模板直接引用宿主 SDK，参考文档同步检查通过。
- 六 RID 从全新暂存目录构建，Windows 三种架构同步生成安装器。原生架构、ZIP 逐文件 SHA-256、许可证、禁止用户数据和 Unix 执行权限检查通过；六个测试运行目录与相应 ZIP 清单完全一致，596 个原便携数据/引导文件逐字节保留，旧运行目录完整归档。
- 实际精简 Windows x64 与 x86 发布程序各通过 40 轮原生窗口还原，覆盖首次还原、仅激活消息、最大化保留、页面保留、最小化缓存释放及托盘还原；x86 在 Windows x64 的 WOW64 环境运行。实际 x64 宿主与现有界面管理插件、清蓝方案的兼容检查通过。
- x64/x86 安装器以独立 QA 身份安装，清单声明的全部程序文件与对应 ZIP 摘要一致，原生架构检查及卸载保留隔离 Data 通过。ARM64 安装器完成编译、版本及载荷来源检查。
- Windows ARM64、Linux x64/ARM64 和 macOS x64 仅交叉构建及静态检查，未在对应设备验证音频、图形、动画和系统安装行为。

此前为滚动边界闪动加入的专项处理已撤销：移除边界滚轮拦截、惯性强制终止、强制关闭自动隐藏的覆盖及对应专项测试，恢复原有滚动行为。发布说明不将此前滚动边界实验视为当前功能。

原有综合套件未全部通过：存在读取未生成的 `Layouts/active.layout.json`、检查旧主页“总览”标题及寻找已隐藏 `LyricsMore` 按钮的过时断言；不将本轮专项通过表述为所有历史测试通过。构建存在 NU1900 在线漏洞元数据访问警告，已缓存依赖成功还原和构建，此项不计为在线审计通过。

发行附件为六个 ZIP、三个 Windows 安装器和一个 SHA256SUMS.txt。测试日志、截图、源文件范围检查和隔离验收结果保存在本地 `artifacts/releases/beta43`，不提交源码 Git。

## 构建与平台

使用 .NET SDK 10.0.401、Release 配置和独立暂存目录构建。发行包核对原生依赖架构、完整 SHA-256、许可证与 Unix 执行权限。

| 目标 | 发行形式 | 验证范围 |
| --- | --- | --- |
| Windows x64 | ZIP、installer | 程序运行、插件加载、安装和卸载 |
| Windows x86 | ZIP、installer | Windows x64 的 WOW64 环境运行、安装和卸载 |
| Windows ARM64 | ZIP、installer | 交叉构建与二进制检查 |
| Linux x64、ARM64 | ZIP | 交叉构建与二进制、权限检查 |
| macOS x64 | ZIP | 交叉构建与二进制、权限检查 |

交叉构建不能代替目标设备上的音频、图形、窗口管理器及高 DPI 验收。

## 回归范围

- 长侧边栏的按钮边界与覆盖式滚动条分离，覆盖左右停靠和普通 / 触摸滚动条。

- SQLite 迁移、恢复与实际聆听计数；七天/二十四小时窗口、边界补零及旧数据兼容。
- 原版与完整界面方案的分类页标题操作、回顶、明暗主题、动态主题色及窄窗口布局。
- 歌词首帧定位、双向转场、取消和连续切页；动画结束不闪回起点。
- 冻结 Contract v1/v2、同 ID 更新、配置保留、权限拒绝与兼容适配。
- 完整界面重组、设置临时接管及撤销恢复；插件原生页面重挂接后保留实例。
- 纯风格、完整界面方案与明暗主题切换时，普通设置变更保留页面实例、输入焦点、编辑草稿和滚动位置，不重复入场；结构设置仍可重新排版。
- 模板直接引用宿主 SDK、六种单平台插件包、可选选择器和统计图表能力。

## 发行包验收

Windows 安装器载荷与对应纯净 ZIP 逐文件核对；隔离卸载保留非程序数据。应用更新包内含版本、RID 与逐文件摘要，不能混用其他架构的 ZIP 或安装器。

开发者可使用 scripts/verify-native-architecture.ps1 和 scripts/verify-clean-desktop.ps1 重复检查发行包。插件接口和测试入口见 [PLUGIN_DEVELOPMENT](PLUGIN_DEVELOPMENT.md) 与 [UNIVERSAL_EXTENSIONS](UNIVERSAL_EXTENSIONS.md)。
