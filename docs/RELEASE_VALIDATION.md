# 桌面发行验证

版本：Nonet 0.4.0-beta.44。插件开发 SDK：4.16.0；程序集兼容基线：4.0.0.0。

## 2026-11-04 桌面 0.4.0-beta.44

本次正式发布整合此前 0.4.0-beta.43 本地修订：触摸/笔窗口缩放、窄窗口工具栏与完整播放按钮组、DPI 布局校验容差、主窗口尺寸记忆及恢复默认按钮。仅提升桌面版本；CLI 0.4.0-beta.32、Android 0.3.0-beta.10 和 SDK 4.16.0 不变。公开源码以已发布 main 为父提交追加纯净快照，保留 Android 普通源码目录，不上传私人插件、清蓝方案源码、运行数据或本地旧开发历史。清蓝 2.0.9 继续作为独立样式项目维护。

beta.44 原生窗口的尺寸保存/冷启动/设置恢复检查在清蓝 2.0.9 下通过，原生触摸/笔模拟缩放与响应式检查通过，默认界面及用户实际导入清蓝 2.0.8 的 DPI 布局专项通过。六个纯净 ZIP、六个运行目录和三个 Windows 安装器已构建，架构、完整 SHA-256、清单、许可与执行权限检查通过，596 个原便携数据/引导文件逐字节保留。Windows x64/x86 实际精简程序各通过 40 轮窗口还原；x64 实际宿主与现用清蓝 2.0.8 的插件兼容检查、x64/x86 安装器载荷及隔离卸载保留 Data 检查通过。日志与摘要保存在本地 `artifacts/releases/beta44`，旧运行目录归档至 `artifacts/releases/previous-20261104-014951`；H 盘运行副本未替换。ARM64、Linux 与 macOS 未做目标设备实机验证；构建出现 NU1900 漏洞元数据网络访问警告，缓存依赖构建成功，不计为在线审计通过。此前歌词/浮窗/下拉框、模板基础检查沿用本轮发布准备前的已通过记录；不将既有综合套件的过时断言列为全部通过。

## 2026-11-04 主窗口尺寸偏好

新增普通窗口逻辑宽高记忆与设置 → 布局 → 恢复默认窗口大小。只保存尺寸，每次冷启动按主屏工作区居中；最大化和最小化不覆盖普通尺寸，托盘隐藏/显示保留运行中的位置，恢复默认在当前屏幕还原并居中。尺寸偏好不受界面方案接管，未扩展插件可写设置或改变旧 Contract。

`--window-size-only` 和 Windows 原生 `--native-window-size` 使用隔离数据库，实际保存并创建四个新窗口/视图模型验证冷启动、按钮恢复、最大化/最小化关闭、缩放后立即退出、旧配置及较小屏幕限制；核对序列化结果不含主窗口位置。原生检查在默认界面与显式清蓝 2.0.9 下通过；布局 DPI 校验、触摸响应式、下拉框与歌词/浮窗专项回归通过，插件模板直接引用及基础检查通过。记录位于本地 `artifacts/window-size`。本次为 0.4.0-beta.43 本地修订，不提升版本或发布 GitHub Release。

六 RID 运行目录、纯净 ZIP 与三种 Windows 安装器已重建，架构、包内逐文件摘要与运行目录一致性检查通过；596 个原便携数据/引导文件逐字节保留。实际 Windows x64 精简发布程序通过清蓝 2.0.9 兼容检查与 40 轮窗口还原；x64/x86 安装器载荷、隔离卸载保留 Data 检查通过。旧运行目录在 `artifacts/releases/previous-20261104-013732`，旧 ZIP/摘要在 `artifacts/releases/local-before-window-size-20261104-013732`，旧安装器按架构归档。H 盘运行副本未替换。Windows ARM64、Linux 与 macOS 仅交叉构建及静态包检查，未在目标设备验证窗口行为。构建保留 NU1900 在线漏洞元数据访问警告，缓存依赖构建成功，不计为在线审计通过。

## 2026-11-04 布局校验的 DPI 取整修订

在用户实际导入的清蓝 2.0.8 下复现：150% 显示缩放、1001.33 DIP 窗口中，队列按钮右边界为 372.67 DIP，父容器宽 372 DIP。框架取整产生一个物理像素差，超过旧固定 0.5 DIP 容差，导致启动/缩放提示“自定义布局不适合”，放大窗口也无法改变固定工具组的误判。新校验按显示缩放换算一个物理像素容差，日志保存几何细节，默认布局采用独立提示，不向用户展示控件 ID 或要求修改行列。

新增 `--layout-validation-only`：以 150% 首次显示，连续覆盖 100%、125%、150%、200% 实际布局缩放、1360/1001.3/1000/999.3/921.6/800/720.3/640 DIP 等宽度及鼠标/触摸往返，默认界面、实际清蓝 2.0.8、清蓝 2.0.9 均不产生回退提示。另将队列按钮人为放大为 100 DIP，确认真实越界仍被拒绝。宽窗口保留播放控制居中，工具区按最小宽度分配，窄窗口优先完整显示。记录位于本地 `artifacts/layout-validation`；本次仍为 0.4.0-beta.43 本地修订。

修复后的六个本地运行目录、六个纯净 ZIP 与三种 Windows 安装器已重建；架构、逐文件摘要、许可和执行权限检查通过，596 个原便携数据/引导文件逐字节保留。实际 Windows x64 精简程序与用户当前导入的清蓝 2.0.8 兼容检查通过；Windows x64/x86 安装器载荷、隔离卸载保留 Data 通过。旧运行目录在 `artifacts/releases/previous-20261104-005822`；H 盘正在运行的副本未由本任务替换。此前一次完整综合套件运行因命令参数组合错误而进入非目标路径，并在播放控制居中断言中断；已修正居中排布并加入专项断言，未将该次运行记为完整通过。

## 2026-11-04 同版本本地触摸与响应式修订

新增窗口触摸/笔独立缩放路径；歌曲工具栏按剩余空间分配搜索与按钮，播放栏预留完整工具组宽度。清蓝独立方案更新为 2.0.9，紧凑播放器分成两行、短窗口主导航独立滚动。未提升客户端版本，也未更新 GitHub Release。

`--touch-responsive-only` 在原版与显式传入的清蓝下通过四边/四角输入、DPI 与最小尺寸、贴边按钮输入保护、七组尺寸/触摸/字号组合、歌单/曲库/历史/分类/插件/统计/设置页面、未选/部分选中/全选状态、按钮可见区域和不重叠检查。`--native-touch-responsive` 对 Windows 实际窗口注入触摸/笔事件并检查窗口尺寸；这属于原生窗口模拟输入验证，不等同于实体触摸屏实测。截图与日志位于本地 `artifacts/touch-responsive`。

本轮队列、下拉框、原版与清蓝浮窗/歌词回归通过，插件参考文档同步检查通过。六个平台运行目录、纯净 ZIP 和三种 Windows 安装器已按同版本重建；架构、包内逐文件摘要、许可和执行权限检查通过，596 个原便携数据/引导文件逐字节保留。实际 Windows x64 精简发布程序与界面管理插件及清蓝 2.0.9 的兼容验收通过；原始旧运行目录在 `artifacts/releases/previous-20261103-234738`，最终构建前的目录在 `artifacts/releases/previous-20261104-001251`；旧 ZIP/安装器与摘要另行归档。Windows x64/x86 最终安装器的全部程序载荷、隔离卸载和 Data 保留检查通过。

## 2026-11-03 桌面 0.4.0-beta.43

本次正式发布仅提升桌面版本；CLI 0.4.0-beta.32、Android 0.3.0-beta.10 与插件 SDK 4.16.0 保持不变。GitHub 源码使用以公开 main 为父提交的干净快照，不上传本地旧开发历史、私人插件、样式项目、使用数据或构建归档；Android 保持已公开内容。

- 下拉框回归先复现指针选择失败，再验证修复后连续选项选择、重新展开、再次点击收回、外部点击传递、嵌套浮窗选择及菜单命令。内部事件沿可视树和 Popup.PlacementTarget 判断归属，关闭通过 ComboBox 自身状态完成，保留模板绑定。
- `--surface-revision-only` 在原版与显式传入的清蓝 2.0.8 下检查同步最大化/还原、背景标题保留、播放栏边缘垂直歌词转场、同帧交接、队列重组后重复打开、快速开合、浮窗选中态和日历关闭。该专项同时运行下拉框输入回归。
- `--queue-motion-only` 和 `--desktop-revision-only` 通过随机完整循环、上一首、手动重选、来源隔离、歌单编辑、故障跳过、歌词更新、SQLite 和离线更新包校验。模板直接引用宿主 SDK，参考文档同步检查通过。
- 六 RID 从全新暂存目录构建，Windows 三种架构同步生成安装器。原生架构、ZIP 逐文件 SHA-256、许可证、禁止用户数据和 Unix 执行权限检查通过；六个测试运行目录与相应 ZIP 清单完全一致，596 个原便携数据/引导文件逐字节保留，旧运行目录完整归档。
- 实际精简 Windows x64 与 x86 发布程序各通过 40 轮原生窗口还原，覆盖首次还原、仅激活消息、最大化保留、页面保留、最小化缓存释放及托盘还原；x86 在 Windows x64 的 WOW64 环境运行。实际 x64 宿主与现有界面管理插件、清蓝方案的兼容检查通过。
- x64/x86 安装器以独立 QA 身份安装，清单声明的全部程序文件与对应 ZIP 摘要一致，原生架构检查及卸载保留隔离 Data 通过。ARM64 安装器完成编译、版本及载荷来源检查。
- Windows ARM64、Linux x64/ARM64 和 macOS x64 仅交叉构建及静态检查，未在对应设备验证音频、图形、动画和系统安装行为。

此前为滚动边界闪动加入的专项处理已撤销：移除边界滚轮拦截、惯性强制终止、强制关闭自动隐藏的覆盖及对应专项测试，恢复原有滚动行为。发布说明不将此前滚动边界实验视为当前功能。

原有综合套件未全部通过：存在读取未生成的 `Layouts/active.layout.json`、检查旧主页“总览”标题及寻找已隐藏 `LyricsMore` 按钮的过时断言；不将本轮专项通过表述为所有历史测试通过。构建存在 NU1900 在线漏洞元数据访问警告，已缓存依赖成功还原和构建，此项不计为在线审计通过。

发行附件为六个 ZIP、三个 Windows 安装器和一个 SHA256SUMS.txt。测试日志、截图、源文件范围检查和隔离验收结果保存在本地 `artifacts/releases/beta43`，不提交源码 Git。

## 构建与平台

使用 .NET SDK 10.0.401、Release 配置和独立暂存目录构建。发行包核对原生依赖架构、完整 SHA-256、许可证与 Unix 执行权限。

| 目标 | 发行形式 | 验证范围 |
| --- | --- | --- |
| Windows x64 | ZIP、installer | 程序运行、插件加载、安装和卸载 |
| Windows x86 | ZIP、installer | Windows x64 的 WOW64 环境运行、安装和卸载 |
| Windows ARM64 | ZIP、installer | 交叉构建与二进制检查 |
| Linux x64、ARM64 | ZIP | 交叉构建与二进制、权限检查 |
| macOS x64 | ZIP | 交叉构建与二进制、权限检查 |

交叉构建不能代替目标设备上的音频、图形、窗口管理器及高 DPI 验收。

## 回归范围

- 长侧边栏的按钮边界与覆盖式滚动条分离，覆盖左右停靠和普通 / 触摸滚动条。

- SQLite 迁移、恢复与实际聆听计数；七天/二十四小时窗口、边界补零及旧数据兼容。
- 原版与完整界面方案的分类页标题操作、回顶、明暗主题、动态主题色及窄窗口布局。
- 歌词首帧定位、双向转场、取消和连续切页；动画结束不闪回起点。
- 冻结 Contract v1/v2、同 ID 更新、配置保留、权限拒绝与兼容适配。
- 完整界面重组、设置临时接管及撤销恢复；插件原生页面重挂接后保留实例。
- 纯风格、完整界面方案与明暗主题切换时，普通设置变更保留页面实例、输入焦点、编辑草稿和滚动位置，不重复入场；结构设置仍可重新排版。
- 模板直接引用宿主 SDK、六种单平台插件包、可选选择器和统计图表能力。

## 发行包验收

Windows 安装器载荷与对应纯净 ZIP 逐文件核对；隔离卸载保留非程序数据。应用更新包内含版本、RID 与逐文件摘要，不能混用其他架构的 ZIP 或安装器。

开发者可使用 scripts/verify-native-architecture.ps1 和 scripts/verify-clean-desktop.ps1 重复检查发行包。插件接口和测试入口见 [PLUGIN_DEVELOPMENT](PLUGIN_DEVELOPMENT.md) 与 [UNIVERSAL_EXTENSIONS](UNIVERSAL_EXTENSIONS.md)。
