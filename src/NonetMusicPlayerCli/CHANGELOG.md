# NonetMusicPlayerCli Changelog

预发布版本；升级前备份自己的 CLI 数据。移除音乐记录不会删除原音频。

## 0.4.0-beta.8 — 2026-10-07

- 同步共享 SDK 4.0 的通用扩展清单与验证器，保留旧 Contract v1；不在无图形 CLI 中执行依赖桌面界面的插件。
- 桌面插件权限策略与 CLI 用户命令保持分离，不改变现有终端语法或键盘 TUI。

## 0.4.0-beta.6 — 2026-10-06

- 同步 SDK 3.4 的可选 Agent 类型与旧 Contract v1 兼容；无图形 CLI 不启用聊天页面插件。
- 共享命令协议保持不变，Agent 的受限工具策略不影响用户终端命令。

## 0.4.0-beta.5 — 2026-10-05

- 同步 SDK 3.3 的平台选择，只安装当前系统所需文件，保持旧多平台包兼容。
- 支持同 ID 高版本原地更新；卸载保留文件时不再移动目录，同版本重新导入可恢复配置并接入。
- 真正删除文件不生成 Retained 副本，原始音频保持不变。

## 0.4.0-beta.4 — 2026-10-05

- 同步共享 SDK 3.2 的可选插件仓库元数据与包版本判断；保持旧 Contract v1 插件兼容，CLI 不显示桌面专用插件页面。
- 主项目提供独立插件开发的唯一 SDK 与打包入口，模板和具体插件不进入本次公开仓库。

## 0.4.0-beta.2 — 2026-10-05

- 同步共享核心及 SDK 3.1：可验证歌词进程插件包，CLI 不启用依赖桌面配置确认的歌词插件。
- 共享音频后端允许宿主安全替换音频标签副本，不影响当前播放句柄。

## 0.4.0-beta.1 — 2026-10-04

- 更名为 NonetMusicPlayerCli，程序及公开命令前缀统一为 nonet。
- 项目、共享核心和 SDK 命名空间同步更名；保留会话内 lmp 前缀兼容。
- SDK 3.0.0 保持独立、无图形依赖，impp Contract v1 不变。
- 增加只构建干净暂存目录的发布选项，避免覆盖现有 CLI 数据。

## 0.3.0-beta.6 — 2026-10-04

- TUI 增加终端与设置栏目，终端在插件和帮助之间；命令输入不再占据其他页面。
- Tab / Shift+Tab 切换栏目，不再使用 F1–F7；终端上下键直接调用命令历史。
- 提供全部 CLI 支持操作的键盘菜单、参数表单、危险操作确认和结果回看，无需输入命令即可使用。
- 设置页直接编辑语言、设备、音量、循环、历史和日志；插件配置从开发者 Schema 生成。
- 歌单可浏览曲目并从选定歌曲开始播放，保留整个歌单队列；命令仍能完整控制。
- 与桌面共用独立 Plugin SDK 验证程序集，保持无图形依赖。

## 0.3.0-beta.5 — 2026-10-04

- 默认 ANSI 交互增加真正的 TUI，提供音乐、歌单、历史、统计、插件、帮助分页和播放状态。
- 共享业务快照与命令；支持键盘选择播放、空格控制、日志回看及行内确认。忙碌事务不丢弃排队的键盘输入。
- 新增 `--tui` / `--repl` 模式，保留无图形环境、管道、JSON 与逐行降级；退出恢复终端状态。
- 拒绝接管含 SQLite 主库的桌面数据目录；音源插件支持可选清理回调，卸载可保留文件或显式删除。

## 0.3.0-beta.4 — 2026-10-03

- 业务命令使用空格分类，例如 `nonet player pause`，不再使用 `--player`。
- 已启动的 CLI 会话可直接输入 `help`、`player pause` 等，也可保留 `nonet` 前缀。
- 保留 `--yes` / `-y` 和 `--no` / `-n`；更新帮助、命令手册和交互提示。

## 0.3.0-beta.3 — 2026-10-03

- 发布启动入口改为 `nonet`，支持系统终端直接执行 `nonet --分类 命令 参数`。
- 统一 `nonet` 前缀、空格分类、`-y` / `-n` 和当前宿主帮助；不再接受点号命令。
- Unicode 查询结果直接显示字符；日志与 Logs 文件夹来自同一记录流，输入命令不写日志。
- 历史默认 1000 行、最高 10000 行，新增 PgUp 有界历史回看与最低显示日志等级。
- 日志文件名仅包含分隔的年月日和版本号。显示筛选不影响固定的磁盘日志记录。

## 0.3.0-beta.2 — 2026-10-03

- 程序、项目与命名空间统一为 `NonetMusicPlayerCli`，不再使用 `.Cli` 后缀。
- 交互改为普通滚动式终端，在 `nonet $ ` 后直接输入；移除固定状态框和底部输入区，退出后保留可复制的系统终端输出。
- 与桌面终端共用提示符、事务日志、输入历史、清屏和行内确认；后台结果不丢失正在编辑的命令。
- 新增 `clear` / Ctrl+L、空行 Ctrl+D 退出；支持长命令换行、中文及文本元素粒度编辑。
- 纯管道、无 ANSI、SSH 和批处理模式采用无控制码逐行输出；保留 `--json`、`--command`、`--stay`。
- 无播放时延迟初始化音频设备，非音频事务不要求声卡或图形环境。
- 发布包包含独立 README、Changelog、使用手册及命令参考。

## 0.3.0-beta.1 — 2026-10-03

- 首个独立 CLI：共用音频解码、标签、随机、本地化、命令和音源插件 Contract。
- 独立持久化数据目录、播放会话、历史、统计和备份恢复；拒绝桌面版的数据目录和外来恢复文件。
- 危险操作需确认或 `--yes`；不执行系统 Shell。支持逐行和 JSON 批处理。
