# Nonet Android 使用手册

## 开始

点击页面左上的菜单按钮或向右滑动打开导航抽屉，向左滑动收起。选择歌单、新建歌单后导入音频；也可选择“以文件夹新建”或“扫描音乐”。点击扫描会先显示确认，只有接受后才申请音乐访问权限并扫描。文件夹导入读取同目录同名 LRC/TXT；单文件授权不保证能够访问同目录其他文件。“我喜欢”不能删除或改名。

设置 → 扫描设备歌曲：按秒或分钟设置最短时长，0 表示不过滤，恰好达到门槛的音频仍导入。可多次添加本地存储文件夹；有指定目录时只扫描这些目录及子目录，没有指定时读取 Android 媒体库。排除目录及其子目录始终不扫描，不会误排除名称仅有前缀相同的其他目录。移除规则只移除扫描配置，不删除文件或既有歌曲。扫描最多 10000 首、目录最多 64 层，超过限制或目录权限失效会提示失败，不把部分结果误报为完成；重新选择目录授权后重试。

主页总览集中展示歌曲与歌单数量、今日聆听、最近 24 小时时长、歌单速览和最近播放；专辑/艺术家入口位于主页下方及侧栏。专辑/艺术家是歌单曲目的分类；浏览歌曲汇总已导入曲目。最近播放包含系统打开/分享的临时音频，临时音频不计统计，加入歌单后按正常曲目统计。

点击右上角搜索图标会进入歌曲浏览，自动显示搜索框、定位输入焦点并请求打开输入法；在浏览页重复点击同样有效。通过侧栏普通进入浏览页不会自动弹出输入法。

## 主题色

设置 → 外观 → 选择主题色：在色轮中点选或拖动，使用亮度和不透明度滑块预览；也可输入 `#RRGGBB`、`#AARRGGBB`，或分别填写 A/R/G/B（0–255）。A 表示不透明度。点击保存后应用，取消保留原设置。文字颜色会结合明暗主题调整对比度。

## 定时关闭

设置 → 定时关闭：选择预设时间，或输入 1–1440 分钟，点击启动定时。计时不依赖设置页，切换页面或进入后台后继续；可返回此处查看倒计时、重新计时或取消。

默认到时停止播放并关闭界面。开启“播放完整歌曲后关闭”后，等待到时正在播放的这一首结束再关闭，单曲循环也不会重播；没有正在播放的歌曲时直接关闭，等待期间暂停、切歌或播放出错也会结束并关闭。关闭前保存进度和统计、断开设备互听；关闭后可正常重新启动。

系统强行停止应用会终止播放和计时。未播放时的休眠闹钟遵循 Android 的调度策略，可能延后；本功能不申请精确闹钟权限。Android 可保留缓存进程，界面与播放服务均已结束。

## 听歌统计

统计页保留累计与日/月/年统计，增加最近 7 天和 24 小时的时长柱状图；主页使用相同的 24 小时数据。时间按真实音频前进记录，暂停、缓冲和跳转不计入；跨小时或午夜自动拆分。旧版仅有每日累计的数据不会被虚构到小时图中，新产生的小时数据与资料库一起保存和备份。

## 播放

点击歌曲播放，底部迷你播放器打开完整播放页，右侧列表图标打开当前队列。点击封面进入歌词，点击歌词区域返回封面；滚动和歌词预览跳转按钮不会触发返回。每次打开歌词直接定位当前播放行。拖动圆形进度柄跳转，左侧时间显示目标位置。模式包括列表循环、单曲循环、降权随机播放；随机避免立即重复（仅一首除外）。

更多 → 导入歌词支持非空 LRC/TXT，最大 2 MB。逐行、方括号/Enhanced LRC 逐字、同时间翻译均可解析。内嵌歌词直接读取音频标签，不另存 LRC；同名独立歌词及手动关联优先，取消关联后不再回退到内嵌歌词。手动浏览不改变当前播放高亮，停止操作 5 秒复位；预览行的播放按钮可跳转。更多 → 导出歌词保存当前关联歌词。

## 管理

侧栏点击“歌单”标题打开歌单总览，右侧加号新建歌单；歌单列表不再单独放置“查看全部”项。

喜欢按钮加入/移出我喜欢。更多提供只读、可复制的信息和添加到歌单。批量模式显示勾选框和三态全选。歌单中长按歌曲整行后上下拖动调整次序，靠近列表上下边缘自动滚动，松手保存；搜索和批量模式中不启用排序。歌曲更多仍提供上移/下移。

歌单卡片的更多按钮位于名称/歌曲数右侧；点击可编辑、换封面、排序、导出 M3U 或删除，长按该按钮拖动也可排序。专辑/艺术家更多只管理封面。最近播放只移出历史，不移除正常歌单引用。浏览歌曲中从全部歌单移除需要确认。上述操作均不删除原音频。

## 外观

主题默认跟随系统，可调整主题色、文字大小和语言。语言立即生效。封面/背景选择后可拖动、双指缩放或滑块裁剪，保存副本，不改变原图；图片最大 20 MB 和 1 亿像素。背景不透明度默认 50%。

最近播放默认 1000 首，可设置 1–10000。恢复默认设置需要确认，不删除歌单。

## Android 集成

文件管理器打开方式可选择 Nonet，也可分享单个/多个音频给 Nonet；仅临时播放，不自动加入歌单。通知、锁屏、媒体按键提供后台控制；拔耳机或切输出会暂停，继续播放保留位置。

若系统限制后台播放，从设置打开后台电池设置，允许后台活动；通知可单独调整。厂商胶囊显示取决于系统支持，标准媒体会话并不等于所有厂商的专用胶囊接入资格。

## 备份恢复

设置 → 数据与备份选择导出位置。包含歌单、历史、统计、设置、歌词和图片，不含原音频、令牌或日志。原音频须另行保管。

恢复需确认并暂停播放，将替换应用数据。换设备、重装或移动文件后，需重新选择源文件夹来授予权限，设备需要重新配对。M3U 导出使用 Android URI 或 Nonet 设备引用，其他应用未必可读取。

## 设备互听

两端接入同一可信局域网，在接收邀请的一端进入“设备互听”并开启共享，复制邀请到另一端连接。邀请五分钟内有效；过期需刷新。接收端接受一次即可互相访问，支持手机之间或电脑之间连接。默认等待 30 秒，可在设置 → 设备互听调整至 10–120 秒，超时或拒绝不授权。Android 后台通知上可直接接受/拒绝；未允许通知时需在期限内打开 Nonet。远端歌单显示在侧栏本地歌单下方，标注“桌面”或“移动”及设备名称。双方播放互不影响。

共享仅开放已导入本地歌单中的歌曲、封面和歌词，不同步历史、统计、设置或远程控制。主动断开和正常退出通知对方并移除临时曲库；暂时停网显示重连，保留配对和歌单，网络恢复后继续原会话。受影响的播放保留进度并续播，手动暂停或切歌可取消自动继续。收藏或加入本地歌单的歌曲保留引用和来源标记。这不是下载，无法离线听对方文件。每次启动默认关闭共享，发起双向连接时会自动开启共享；通知中可停止服务。Doze 仍可能暂停实际联网，用户可在设备互听页打开系统后台电池设置；强制停止进程或共享端重启后需重新配对。

切换应用、暂停播放或关闭屏幕不会主动断开已建立的互听连接。连接期间保留前台共享通知，并按需保持后台 CPU 与现有 Wi-Fi 网络；断开后释放保护。单次心跳延迟先重试，不立即清空曲库。系统强制停止、从最近任务移除、手动停止共享或真实网络中断仍会结束连接；厂商电池管理强行终止进程时，需允许 Nonet 后台活动。

更多协议与防火墙说明见 [设备互听](LAN_LIBRARY.md)。

## 应用更新

启动 Nonet 时会自动检查 GitHub 的 Android 新版本；也可打开设置 → 关于 → 检查更新。仓库链接使用系统浏览器打开。Android 与桌面版本独立，不会把桌面压缩包当作手机更新。

更新弹窗显示只读版本说明，可选择下载、后台下载或暂不更新。前台下载期间可转到后台，通知显示进度；点击通知或设置中的查看更新可返回下载弹窗。弹窗和通知均可取消下载，取消后删除临时数据。未允许通知时保留前台进度，并提示通知不可用。

下载完成后自动校验并请求 Android 安装器。首次可能需要允许 Nonet 安装未知应用；返回后继续安装。后台完成时点击安装通知即可进入，无需寻找文件。系统可能禁止后台直接弹出安装页面，Nonet 不绕过此限制，也不静默安装。

取消系统安装不会删除音乐数据，可在设置重试；放弃待安装更新可删除缓存包。成功升级后下次启动自动清理旧更新缓存。当前测试版须使用同签名 APK 覆盖升级，不要卸载旧版来绕过签名检查。

## 故障处理

- 歌词：在完整播放页更多中选择 LRC/TXT，勿选择图片或空文件。
- 音频：检查源文件移动、授权撤回、设备连接和防火墙。坏音频自动跳过，全部失败停止。
- 无专辑/艺术家：标签为空的文件仍在歌单，但不建立空名称分类。
- 覆盖安装：必须相同签名，不要通过卸载旧版尝试修复，以免删除应用数据。
- 后台卡顿：反馈设备型号、系统版本、音频格式和应用 Logs。厂商后台限制仍需真机验证。
