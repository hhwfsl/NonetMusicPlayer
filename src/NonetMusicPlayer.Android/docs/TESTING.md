# Android 测试

## 环境

Windows / JDK 21 / Gradle 8.12 / Android SDK 36。
设备环境为 Android 15（API 35）x86_64 模拟器，含手机竖屏/横屏、320 dp 小屏、平板尺寸切换。测试音频仅在 androidTest 资产中，正式 APK 不含测试音频。

## 可重复运行

```powershell
./gradlew.bat :app:testDebugUnitTest
./gradlew.bat :app:connectedDebugAndroidTest
./gradlew.bat :app:assembleRelease
```

DomainTests：LRC 多种时间格式、逐字/翻译、降权随机、有界输入。
AudioImporterTests：APIC 封面、USLT 内嵌歌词、独立歌词导入。
EmbeddedLyricsTests：ID3 v2.2/v2.3/v2.4、UTF-16、扩展头、去同步、FLAC 大封面跳过、Ogg/Opus 跨页、M4A ©lyr、WAV ID3 和损坏标签边界。
RepositoryTests：排序/收藏、统计不重建曲目、临时播放/历史、持久化、私网邀请与断线引用保留。
PlayerUiTests：真实媒体播放/跳转/自然结束、系统控制、无效队列、语言/主题、横屏/平板/小屏、歌词即时导入、重复后台/前台转换与灭屏、备份恢复、图片裁剪。

MobileRevisionTests：侧栏滑动开合及原图图标、歌单单一底部操作入口、长句歌词首次定位与重复进入、封面/歌词双向切换、连续轨道及圆形拖动柄。

UpdateVersionTests / UpdateRulesTests：数值版本排序、Android 标签过滤、资产摘要、长度、受限 HTTPS 重定向及非法安装包拒绝。

更新完整流程测试 `UpdateFlowTests` 需要一个**同包名、同签名、更高 versionCode/versionName** 的隔离 QA APK。将其放到模拟器 `/sdcard/Android/data/app.littlemusicplayer.android/files/qa/update-fixture.apk`，在开始 instrumentation 前执行 `adb shell appops set app.littlemusicplayer.android REQUEST_INSTALL_PACKAGES allow`。测试只打开系统安装确认页并取消，不执行安装。缺少夹具或权限会明确跳过该项，不能把跳过计为安装流程通过；结束后在仪器测试之外恢复 appops 为 `default`。QA 包不发布到 GitHub，也不进入源码或正式 APK。
