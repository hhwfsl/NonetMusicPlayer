# 局域网设备互听

## 使用

1. 两端接入同一可信局域网，并导入本地歌曲到歌单。
2. 在接收邀请的一端打开“设备互听”，开启“共享本机音乐”。发起连接的一端自动启动本机共享，以建立双向读取。
3. 复制连接邀请，粘贴到另一端的设备互听页并连接。邀请五分钟内有效，过期后刷新。
4. 接收端接受一次即可建立双向连接，支持电脑↔手机、电脑↔电脑及手机↔手机。默认等待 30 秒，可在设置调整至 10–120 秒；拒绝或超时不授权。Android 后台通知支持直接接受/拒绝，无须保持界面焦点。
5. 连接后，远端歌单显示在侧栏本地歌单下方，附“桌面”或“移动”及设备名称。点击可在本机独立播放；设备页只管理连接，断开后临时歌单消失。
6. 将歌曲加入“我喜欢”或自己的歌单可保留引用和提供设备的类型。这不是下载，离线时不能播放；再次连接同一设备后恢复可用。
7. 普通切后台、暂停音乐和灭屏不关闭互听。连接或配对期间，前台服务按需续租 CPU 唤醒保护，并保留已连接的 Wi-Fi 网络；无连接时释放保护，不强制打开 Wi-Fi，不绑定整个应用的网络。
8. 主动断开或正常退出会通知另一端。正常心跳间隔五秒，单次请求最长四秒；失败后按 2、4、8、15 秒退避重试。连续失败仅显示暂不可达，配对、歌单与引用始终保留，不因后台时长撤销认证。恢复网络、唤醒或退出休眠时主动重试，受影响的播放保留原进度并续播；手动暂停或切歌可取消自动继续。明确撤销令牌或收到主动断开立即结束会话。

共享只包含本机已导入歌单中的本地音频、音乐标签、封面、歌词，不转发云端或其他设备歌曲，不同步设置、最近播放、统计或播放器操作。明确断开、关闭共享或正常退出移除临时曲库；暂时停网不移除曲库。收不到结束通知时无法可靠区分停网与异常关机，因此保持重连，可手动断开。

Android Doze 可能暂停网络并忽略唤醒锁，前台服务不是永久联网的保证。设备互听页提供标准电池设置入口，由用户选择允许后台活动；应用不自动加入白名单，不依赖厂商接口。进程被强制停止、共享服务重启、IP/端口或证书改变后需要重新配对。会话仅驻留内存，不放宽 TLS 指纹、来源与 Bearer 检查。

音频由 Media3 按需读取并在手机独立解码，首播约 250 ms 预缓冲后开始，断流重缓冲仍保留 2.5 秒保护。远端有网络首包与服务器响应延迟，不保证等同本地文件；快速切歌直接取消旧 HTTP 请求，不先等待旧请求完成。

Windows 首次共享可能需要允许专用网络的防火墙访问。无须关闭防火墙，不要将端口映射到公网。访客 Wi-Fi、无线隔离、VPN 或系统后台限制可能阻止连接。Android 共享期间显示前台通知，可在通知中停止。

## 协议 v1

采用双端一致的只读 HTTPS API，邀请包含私网数字 IP、端口、证书 SHA-256 指纹和短期随机密钥。客户端固定证书并禁用重定向，不向其他地址转交认证。

- `POST /v1/pair`：限长 JSON，提交 key/deviceId/name 和可选 duplex=true；有效邀请仍需接收端用户接受。默认等待 30 秒，可设 10–120 秒；接受后返回 deviceId/name/token/protocol 及可选 duplex 标志，拒绝或超时不签发令牌。
- `POST /v1/duplex`：以已批准会话的 Bearer 提交反向 port/fingerprint/token，回连主机只取实际 TCP 来源，固定证书指纹，不接受任意 URL。只有接受后才发送反向读取凭据，授权一次使用。
- `POST /v1/disconnect`：有效会话撤销该设备的访问，并通知上层解除连接；收不到通知时进入不可达重连状态，不推断为已撤销。旧 v1 只读接口保留，新界面要求双向能力。
- `GET /v1/info`：设备标识与曲库 revision，用于心跳和变更检测。
- `GET /v1/catalog?offset=N`：每页最多 200 首，首响应包含歌单，最大 20000 首与 2000 个歌单。可选 `deviceKind` 为 desktop/mobile/unknown，用于来源标记，旧设备不提供时显示通用设备标签。两端均需更新才能完整使用审批与平台标记。
- `GET/HEAD /v1/audio/{id}`：增量音频流，支持单个字节 Range、后缀 Range、206/416 与寻址。
- `GET/HEAD /v1/artwork/{id}`、`/v1/lyrics/{id}`：按已授权歌曲 ID 获取资产。

所有 GET/HEAD 需要内存 Bearer 会话；已批准会话不因空闲过期，明确撤销或共享服务结束后失效。服务端限制会话数、并发、请求大小及配对频率。不接受任意文件路径，也没有播放控制、上传、删除或系统命令端点。歌词最多 2 MiB、封面最多 5 MiB；音频流按固定缓冲复制，不整首解码到内存。

桌面实现位于主项目 `Core/Network`，与 Avalonia 页面分离。Android 不提供插件或终端；桌面扩展接口说明见主项目 `docs/UNIVERSAL_EXTENSIONS.md`，配对秘密不向插件公开。
