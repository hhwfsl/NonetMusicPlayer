# Changelog

## 0.3.0-beta.9 — 2026-10-22

- 启动自动检查 GitHub 更新，弹窗展示版本变化；设置“关于”支持手动检查和点击 GitHub 仓库导航。
- 前台下载进度弹窗可随时转到后台，通知提供进度、返回弹窗和取消；取消或失败删除本次临时文件。
- 完成后校验 SHA-256、包名、递增版本、设备要求与签名，进入 Android 安装流程；后台完成通过通知直接进入，不需要定位 APK。首次安装更新仍需系统授权和用户确认。
- 公开 Android 源码并规范构建、更新与测试文档；不公开 iOS、签名私钥、用户数据、缓存和旧本地 Git 历史。

## 0.3.0-beta.8 — 2026-10-22

- 配对关系与网络可达性分离；后台休眠、长时间空闲及临时停网只进入重连状态，不清空远端歌单、不撤销认证。恢复网络或唤醒时自动重试，沿用原会话。
- 互听播放遇临时网络错误时保留歌曲和进度，恢复后续播；主动暂停或切歌可取消自动继续，明确断开仍立即清理临时引用。
- Media3 直接拥有可取消的已配对 HTTP 请求，移除嵌套网络调用，改善快速切歌；首播预缓冲缩短至约 250 ms，保留断流保护和增量解码。
- 设备互听页显示可达/重连状态，提供 Android 标准后台电池设置入口；不依赖特定手机品牌，不自动修改系统白名单。

## 0.3.0-beta.7 — 2026-10-19

- 双向互听将对端的已认证心跳计入在线状态，不因单方向的后台网络延迟撤销仍有效的连接。
- 连续失败且约三十秒没有有效通信时才结束会话；空闲、暂停、切换应用及熄屏不主动断开，明确撤销和主动断开仍立即处理。
- 日志记录主动断开、对端断开、凭据撤销与心跳失联原因，不记录认证令牌或文件路径。

## 0.3.0-beta.6 — 2026-10-19

- 互听连接的后台保护由前台服务统一管理：连接/配对时按需续租 CPU 唤醒保护并保留已连接的 Wi-Fi 网络，断开或停止共享后释放，不依赖 Activity 焦点或音乐是否正在播放。
- 心跳采用连续失败和有限恢复窗口，单次超时不再清空连接与远端歌单；明确撤销及主动断开仍立即生效。
- 右上角搜索按钮进入歌曲浏览后自动滚动到搜索框、获取输入焦点并打开输入法；已在该页时重复点击同样生效，普通返回和后台恢复不重复抢占焦点。

## 0.3.0-beta.5 — 2026-10-19

- 一次配对建立双向互听，支持手机、平板和桌面设备之间连接；来源按设备显示“桌面”或“移动”。
- 在后台通过通知直接接受或拒绝请求，无须保持应用焦点。默认等待 30 秒，设置支持 10–120 秒；过期通知不能授权。
- 主动断开与正常退出发送结束通知，异常失联由心跳检测；远端临时歌单自动消失，收藏和已添加到本地歌单的引用保留。
- 逐字歌词使用帧时钟平滑推进，缓存字形位置并合并裁剪，只绘制一次着色文本；原文和翻译保持同步。

## 0.3.0-beta.4 — 2026-10-19

- 扫描设备歌曲前显示确认，确认后才请求媒体权限或开始扫描。支持最短时长过滤（秒/分钟）、包含目录与排除目录，并持久化到 SQLite 设置。
- 指定包含目录后只在授权的本地文件夹内扫描；排除目录及子目录始终优先。重叠目录去重，目录权限失效不回退全设备扫描，过滤不移除已导入歌曲。
- 主页移除浏览歌曲按钮，侧栏入口保持不变。
- 设备互听的远端歌单移至侧栏歌单分组内，附桌面端/移动端和设备名称；断线自动移除临时导航，本地歌单保持不变。
- 被连接设备需要明确接受连接后才开放曲库；拒绝、60 秒超时和停止共享不授权。后台接入请求通过通知提示，返回应用确认。

## 0.3.0-beta.3 — 2026-10-19

- 修复文件夹导入在没有独立 LRC 时清空内嵌歌词的问题，旧导入记录可按需从源文件重新读取，无需重新导入。
- 扩展 ID3 v2.2/2.3/2.4、FLAC/Vorbis、Ogg/Opus、M4A/MP4 和 WAV ID3 歌词标签读取；大封面与音频直接跳过，内嵌歌词不生成 LRC 副本，手动指定与取消关联仍优先。
- 封面/歌词使用固定尺寸、居中叠放的淡入淡出，修复切换时封面闪现到左上角；横屏同步使用此转场。
- 侧栏移除歌单“查看全部”项，点击“歌单”标题进入总览。
- 歌单支持长按整行拖动排序、拖动预览及边缘滚动，松手后保存；移除行尾排序柄，喜欢与更多操作右对齐，保留辅助功能上移/下移。

## 0.3.0-beta.2 — 2026-10-18

- 界面按轻量分组风格重构，移除 Material3 依赖；按钮、输入框、开关、勾选框、弹层、日历及进度控件由 Compose Foundation 实现，保留深浅主题、三语与辅助功能语义。
- 启动图标改为完整用户原图，不裁切或预加圆角，并置于 Android 自适应图标安全区域；侧栏品牌前显示相同原图。
- 侧栏支持向右滑动展开、向左滑动收起，跟随手势并平滑落位；保留侧栏滚动位置，不抢占横向曲目列表及进度条手势。
- 歌单卡片移除封面上两个操作按钮，合并为文字信息右侧的更多按钮；支持长按拖动和菜单上移/下移。
- 修复歌词首次进入、重新进入及长句翻译时的定位跳动：首帧前直接居中，以真实视口坐标计算位置，后续单次平滑跟随。
- 播放页点击封面进入歌词，点击歌词区域返回封面；预览、跳转按钮和当前播放高亮保持独立。
- 进度条改为连续细轨道与圆形拖动柄，移除柄两侧间隙、白条和端点圆点，保留点击、拖动与辅助功能调节。

## 0.3.0-beta.1 — 2026-10-18

- 改为紧凑网页式平面界面：内容内导航、推入式抽屉、全宽迷你播放器；移除顶部应用栏与底部导航标签。
- 重新组织主页总览、分类卡片、歌单操作区；增加队列入口、设置搜索、本机音乐扫描和按文件夹新建歌单。
- 新增与桌面端双向局域网设备互听，HTTPS 配对、只读歌单、按需封面/歌词与流式音频，两端独立播放。
- 设备歌曲可加入本地歌单或收藏，使用“移动”标识；断线清除临时曲库，保留已保存引用与重连能力。
- 移除旧任意服务器连接器与其配置；共享默认关闭，Android 开启共享时显示可停止的前台通知。
- 保留后台媒体服务、圆形进度柄、逐行/逐字歌词、导入导出、统计、备份恢复和系统打开方式；歌词可取消关联。
- 手机、横屏、平板、小窗口使用自适应布局；一万首歌单按可见行惰性组合，队列留在进程内而非整批写入 Binder。
- 应用图标与桌面一致；沿用原应用 ID 和签名以支持覆盖安装，发布目录仅保留最新 APK。

## 0.2.0-beta.1 — 2026-10-05

### 播放与歌词

- 使用音频优先级解码线程，增加按时间优先的有界缓冲，降低切换应用时播放受到干扰的风险。
- 播放统计不再重读全部曲目和歌单；当前曲目使用 ID 索引，日志写入后台串行执行。
- 修复 LRC 文件选择过滤、导入关联目标、重复导入后的缓存失效与立即刷新；增加 UTF-16 BOM 支持及无效/超限提示。
- 支持方括号和 Enhanced LRC 逐字时间、原文/翻译逐字推进；空白行不展示，手动预览 5 秒复位。
- 支持 MP3 USLT / FLAC LYRICS 内嵌歌词，不另存 LRC，仍可手动指定。
- 圆形进度拖动柄和目标时间；封面/歌词淡入淡出。

### 管理与界面

- 名称改为 Nonet，主页仅显示主页标题。
- 补齐浏览歌曲、批量选择、三态全选、排序柄、M3U/歌词导出。
- 最近播放仅移除历史，专辑/艺术家仅分类；全歌单移除与歌单删除需确认，不删除源音频。
- 增加封面/背景交互裁剪、主题背景及不透明度、备份恢复、清空历史和使用手册；修复裁剪过程中位图提前释放。
- 补齐日/月/年统计的最常播放歌曲和最长聆听艺术家。
- 600 dp 以上侧边导航，横屏/平板分栏播放器；小屏操作菜单可滚动。
- 修复实时语言切换后设置文件选择器丢失 Activity 宿主的崩溃。

### 系统与发布

- 增加 Android 音频分享与多文件临时队列、系统通知和后台电池设置入口。
- 保留旧应用 ID、旧数据库兼容和原签名，以便覆盖升级。
- Android 不提供插件和终端。
- 发布目录只保留最新 APK；R8 代码与资源裁剪，不包含测试音频。
- 标准媒体通知/锁屏已接入；荣耀胶囊及 MagicOS 9 后台策略需真机验证。
