# Nonet Android

当前版本：`0.3.0-beta.9`。

面向手机、平板和多窗口的原生 Android 音乐播放器。项目由 AI 开发，未经过独立人工代码审查。当前在 Windows 构建主机与 Android 15 模拟器验证；荣耀 REA-AN00 / MagicOS 9 尚需真机回归。

本目录作为普通源码目录纳入 [NonetMusicPlayer](https://github.com/hhwfsl/NonetMusicPlayer) 主仓库，不是子模块。Android 不提供插件或终端。许可沿用项目 GPL-3.0-only。

## 构建

| 技术 | 版本 |
| --- | --- |
| Kotlin / Compose 编译插件 | 2.1.20 |
| Compose BOM | 2025.05.01 |
| AGP / Gradle | 8.10.1 / 8.12 |
| Media3 | 1.6.1 |
| JDK | 17–21（本地使用 21） |
| compile / target / min SDK | 36 / 36 / 28 |
| 数据库 | Android SQLite（外键、事务、WAL） |

安装 Android SDK 36、Build Tools 35.0.0，在未提交的 local.properties 填写 sdk.dir，或设置 ANDROID_HOME。不要同时设置相互冲突的 ANDROID_SDK_HOME 和 ANDROID_USER_HOME。

```powershell
./gradlew.bat :app:assembleDebug
./gradlew.bat :app:testDebugUnitTest
./gradlew.bat :app:connectedDebugAndroidTest
./gradlew.bat :app:assembleRelease
```

Linux/macOS 使用 ./gradlew。release 启用代码和资源裁剪。目前本地测试 APK 使用调试签名，不适合应用商店发布。覆盖升级必须沿用原签名，可传入 -PnonetSigningStore="原证书路径"。

软件显示名称为 Nonet；内部应用 ID 保留 app.littlemusicplayer.android，保证旧 APK 覆盖升级、数据和 content URI 授权兼容。检测到旧 littlemusicplayer.db 时继续使用，不丢弃数据。

## 🔄 应用更新

每次启动检查一次 GitHub Android Release，发现新版本弹出只读更新说明；设置 → 关于也可手动检查并打开 GitHub 仓库。标签与桌面独立，采用 `android-v<版本>`，预发布安装包检查对应的新预发布；正式版本不自动切入预发布。

下载可在弹窗查看进度，也可转到后台通过通知查看和取消；点击进度通知可返回弹窗。取消或失败会删除临时数据。完成后校验 SHA-256、包名、版本和签名，前台直接请求系统安装；后台完成显示安装通知，点击即可进入，无需寻找 APK。Android 可能要求先允许 Nonet 安装未知应用，安装始终由用户确认，不静默执行。

安装成功后，下次启动清理缓存 APK；未安装的已验证包可保留重试。不同签名、降级包或缺少校验的附件不作为可安装更新。服务被系统强制终止时不保证下载继续，下一次启动会清理残留并允许重试。详见 [更新协议与测试](docs/UPDATES.md)。

## 🎧 使用范围

- 首页总览、专辑、艺术家、最近播放和日期统计；浏览歌曲入口保留在侧栏，不占用主页。
- 扫描前确认；设置中保存最短时长（秒/分钟）、扫描目录与排除目录。指定包含目录后只扫描这些授权目录，排除规则优先，不删除已导入的音乐。
- 歌单创建/编辑/删除、喜欢、文件/文件夹导入、批量操作、长按整行拖动排序、M3U 导出。
- 迷你播放器与完整播放页，圆形进度柄与目标时间、三种播放模式。
- 歌词导入/导出、逐行与逐字 LRC、原文/翻译、5 秒预览复位；MP3 ID3、FLAC/Vorbis、Ogg/Opus、M4A 和 WAV ID3 内嵌歌词不另存文件，旧导入记录可按需补读。
- 主题/语言/文字缩放、背景及不透明度、封面交互裁剪。
- 元数据/歌词/图片备份恢复，恢复默认设置。
- 标准后台媒体服务、通知/锁屏/媒体按键、输出切换暂停、音频打开方式与分享。
- 可主动启停的局域网设备互听：一次配对双向读取桌面或移动设备的本地歌单并独立流式播放，收藏或加入歌单后保留引用和“桌面”/“移动”来源，不同步其他数据。

0.3.0-beta.2 使用 Compose Foundation 和自有 NonetTheme / NonetWidgets 实现轻量分组、平面卡片与紧凑列表；不使用 Material3 控件或 WebView。图标库仅提供线条图标资源，不引入 Material 组件体系。没有固定顶部应用栏或底部标签导航。导航位于内容内，菜单或左右滑动打开/关闭推入式抽屉，底部只保留全宽迷你播放器与队列入口。840 dp 以上抽屉与内容并排；横屏播放器分栏，列表和网格惰性渲染，页面滚动状态由 SaveableStateHolder 保留。保留系统返回、文件选择器、辅助功能语义与触摸操作表。

旧任意服务器 JSON 连接器已移除。设备互听需要双方开启 Nonet、同一可信局域网与短期邀请；HTTPS 固定证书，密钥只保存在内存。提供方仅共享本地音频，不代理第三方音源，退出默认关闭；Android 共享使用前台通知。明确断开后移除临时歌单及未保留曲目，暂时停网则保留配对与曲库，自动重试。

接收端需要明确接受连接；默认等待 30 秒，可在设置中调整至 10–120 秒。后台通知支持直接接受/拒绝，不要求保持 Activity 焦点。超时或拒绝不授权。远端歌单显示在侧栏歌单分组，标注来源及设备名；设备互听页仅负责管理。连接期间前台服务按需持有有界 CPU 唤醒租约和现有 Wi-Fi 网络请求，普通切后台、暂停播放和灭屏不主动断开；无连接时释放保护。探测失败退避重试，始终保留配对；网络恢复或唤醒触发重试，明确撤销或主动断开立即生效。Android Doze 仍可能暂停实际传输，不能用前台通知保证永久联网。进程被强制停止、共享端重启或地址/证书改变后需要重新配对；不会为恢复放宽认证。

## 播放与数据

ExoPlayer 使用音频优先级解码线程，播放/缓冲时持有唤醒锁，暂停即释放。音频按需读取，不预解码整首歌曲；8 MiB 缓冲目标、15–45 秒时间阈值，时间优先可能暂时超过字节目标，因此不是硬内存上限。界面失焦不重建播放器或重置进度。

统计写入只刷新统计数据，不重读曲目和歌单；当前曲目用 ID 索引查找；日志异步串行写入。文件仍在原位置，应用私有空间保存 SQLite、Lyrics、Artwork、Images 和按日期/版本命名的 Logs。

歌词最大 2 MB，支持 UTF-8、UTF-16 BOM、GB18030。图片最大 20 MB、1 亿像素，先降采样，裁剪保存副本。备份资产最大 100 MB，不包含原音频、认证令牌或日志。换设备或重装后需重新授予源文件访问权限。

M3U 保存 Android content URI 或 Nonet 设备引用，其他播放器不一定拥有访问权限或支持此引用；不是包含原音频的可移植资料库。

## 系统边界

“灵动岛”/荣耀胶囊不是通用 Android API。本版提供标准 MediaSession、媒体通知和锁屏元数据，不承诺所有 OEM 胶囊展示或后台白名单。厂商限制后台时，可从设置进入系统后台电池策略和通知设置。

解码受设备 MediaCodec 能力影响。不绕过 HTTPS 证书校验，不提供浮动桌面歌词或任意代码执行插件。
