# 精准歌词工具

Nonet 0.3.0-beta.4 的声明式 UI 插件示例。插件中心负责安装、启用和卸载；启用后，歌词页的“更多”菜单与插件侧栏均提供入口。

## 使用

1. 导入 `sample.lyrics-timing.impp` 并启用插件。
2. 打开精准歌词工具，默认选中当前播放歌曲；可通过“选择标注歌曲”改选音乐中的其他歌曲，再选择 LRC 或 TXT 文件。改选时不会立即切歌。
3. 点击“开始标注”，歌曲从头播放。第一行固定为 `[00:00.000]`，之后每次按空格为下一行记录音频时钟的毫秒时间。
4. 可撤销上一行，再跳转到合适位置继续。全部标注后点击“标注完成并保存”。已有歌词会要求确认替换。
5. LRC 保存到应用的歌词文件夹并关联当前歌曲，原始输入文件不改变。取消不写入文件。

标注期间不能切歌或更改播放方式。曲终暂停，不循环或跳到下一首。离开页面、禁用或卸载插件会取消未保存标注并解除限制。允许暂停、继续和在所选歌曲内调整进度。空行、标准元数据和已有时间标签不参与标注；每一个实际文本行分别标注，原译文如需相同时刻可在保存后编辑 LRC。

应用窗口内即使焦点在播放栏按钮或歌词列表，空格也会标注下一行而不会暂停歌曲；按住空格只标注一次。标注期间不能改选歌曲，完成或取消后恢复选择。本工具不注册其他应用中的全局空格热键。

## 文件与能力

- `package/manifest.json`：权限、页面入口、`lyrics.more` 菜单贡献。
- `package/page.json`：`lyrics-timing` 原生部件。
- `build.ps1`：仅打包清单和实际使用的页面，不包含源码、文档或运行时。

此插件通过契约获得歌词编辑和受限播放租约，不执行任意脚本、XAML 或系统命令。更多接口见主项目 `docs/PLUGIN_DEVELOPMENT.md`。

## 打包

```powershell
pwsh -File ./build.ps1
```

输出在本目录的 `dist/sample.lyrics-timing.impp`。只接受 `.impp` 格式。
